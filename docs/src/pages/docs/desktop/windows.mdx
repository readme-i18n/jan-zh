# Windows 安装指南

## 兼容性要求

**系统需求:**

- **操作系统**: Windows 10 或更高版本
- **CPU**

<Tabs items={['Intel', 'AMD']}>
<Tabs.Tab>
- Intel: Haswell (Q2 2013) or newer
- Intel Celeron/Pentium: Tiger Lake (Q3 2020) or newer
</Tabs.Tab>
<Tabs.Tab>
- Excavator processors (Q2 2015) and newer.
</Tabs.Tab>
</Tabs>

<Callout type="info">
处理器必须支持 **AVX2 或更新指令集**。查看[完整支持的处理器列表](https://en.wikipedia.org/wiki/Advanced_Vector_Extensions#CPUs_with_AVX2)。
仅支持 AVX 指令集的处理器性能会显著下降。
</Callout>

**内存 (RAM)**

- 8GB → 最高支持 30亿参数模型(int4量化)
- 16GB → 最高支持 70亿参数模型(int4量化)
- 32GB → 最高支持 130亿参数模型(int4量化)

<Callout type="info">
新一代内存能提供更好的性能表现。
</Callout>

**GPU 要求:**

- 6GB 显存 → 最高支持 30亿参数模型
- 8GB 显存 → 最高支持 70亿参数模型
- 12GB 显存 → 最高支持 130亿参数模型

<Callout type="info">
建议 NVIDIA、AMD 或 Intel Arc 显卡至少配备 6GB 显存。
</Callout>

**存储空间:** 应用程序和模型至少需要 10GB 可用空间

## 数据文件夹

默认安装路径：

```sh
# Default installation directory
~\Users\<YourUsername>\AppData\Roaming\Jan\data
```

完整文件夹结构详情请参阅 [Jan 数据文件夹](/docs/data-folder)

## GPU 加速

<Tabs items={['NVIDIA GPU', 'AMD GPU', 'Intel Arc GPU']}>

<Tabs.Tab>

<Steps>

### Step 1: Verify Hardware & Install Dependencies
**1.1. Check GPU Detection**

Verify GPU is recognized:
- Right-click desktop > NVIDIA Control Panel
- Or check Device Manager > Display Adapters

**1.2. Install Required components**
**NVIDIA Driver:**
1. Install [NVIDIA Driver](https://www.nvidia.com/en-us/drivers/) (version **470.63.01 or higher**)
2. Verify installation:

```sh
nvidia-smi
```

**CUDA Toolkit:**
1. Install [CUDA toolkit](https://developer.nvidia.com/cuda-downloads) (**11.7 or higher**)
2. Verify installation:

```sh
nvcc --version
```
### Step 2: Enable GPU Acceleration

Navigate to **Settings** (<Settings width={16} height={16} style={{display:"inline"}}/>) > **Hardware** > **GPUs**
and toggle the **ON** switch if not enabled.

</Steps>

## 卸载 Jan

<Steps>

### 步骤 1：通过控制面板移除应用程序

1. 打开 **控制面板**
2. 进入 **程序** 部分
3. 点击 **卸载程序**
4. 搜索 **Jan**
5. 点击 **三点图标** > **卸载**
6. 再次点击 **卸载** 确认
7. 点击 **确定**

### 步骤 2：清理残留文件

移除应用数据：

1. 导航至 `C:\Users\[username]\AppData\Roaming`
2. 删除 Jan 文件夹

或通过 **终端** 操作：

```sh
cd C:\Users\%USERNAME%\AppData\Roaming
rmdir /S Jan
```
</Steps>

<Callout type="warning">
已删除的数据文件夹无法恢复。请先备份重要数据。
</Callout>
