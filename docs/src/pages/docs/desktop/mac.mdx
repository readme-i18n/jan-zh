# Mac 安装指南

Jan 原生支持 Apple Silicon 和 Intel 芯片的 Mac 设备。

## 兼容性要求

### 最低配置

您的 Mac 需要满足：

- **操作系统:** MacOSX 13.6 或更高版本
- **内存:**
  - 8GB → 可运行最高 30 亿参数模型
  - 16GB → 可运行最高 70 亿参数模型
  - 32GB → 可运行最高 130 亿参数模型
- **存储空间:** 10GB 以上可用空间

### Mac 性能指南

<Callout type="info">
**Apple Silicon 芯片 Mac** 默认启用 Metal GPU 加速，性能优于仅支持 CPU 运算的 **Intel 芯片 Mac**。
</Callout>

**Apple Silicon (M1, M2, M3)**

- 默认启用 Metal 加速
- 支持 GPU 加速运算

**Intel 芯片 Mac**

- 仅支持 CPU 运算
- 标准性能表现

_查看处理器信息：点击左上角苹果菜单 → 关于本机_

## Jan 数据文件夹

默认位置：

```sh
# Default installation directory
~/Library/Application\ Support/Jan/data
```

详情请参阅 [Jan 数据文件夹](/docs/data-folder)。

## 卸载 Jan

<Steps>

### 第一步：移除应用程序
1. 如果 Jan 正在运行，请先关闭
2. 打开 **访达**
3. 进入 **应用程序** 文件夹
4. 找到 Jan
5. 选择移除方式：
  - 拖拽至 **废纸篓**
  - 右键点击 → **移到废纸篓**
  - **Command-Delete** 快捷键

### 第二步：清理数据（可选）

在 **终端** 中运行以下命令以删除所有数据：
```bash
rm -rf ~/Library/Application\ Support/Jan/data
```
</Steps>

<Callout type="warning">
此操作将永久删除所有数据。如有需要，请提前创建备份。
</Callout>
