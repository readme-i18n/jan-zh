# Anthropic

Jan 通过 API 集成支持所有 [Anthropic 模型](https://anthropic.com/)，您可以直接与 Claude 最新的 Opus、Sonnet 和 Haiku 模型进行对话。

## 将 Anthropic API 集成到 Jan

<Steps>

### 步骤 1：获取 API 密钥
1. 访问 [Anthropic 控制台](https://console.anthropic.com/settings/keys)并登录
2. 创建并复制新的 API 密钥，或复制现有密钥

<Callout type='info'>
请确保您的 API 密钥有足够的额度
</Callout>

### 步骤 2：配置 Jan

1. 进入 **设置** (<Settings width={16} height={16} style={{display:"inline"}}/>)
2. 在 **模型提供商** 下选择 **Anthropic**
3. 输入您的 **API 密钥**

<br/>
![Anthropic](../_assets/model-management-06.png)
<br/>

### 步骤 3：开始使用 Anthropic 模型

1. 在任何现有 **聊天** 中或创建新聊天
2. 从 **模型选择器** 中选择 Anthropic 模型
3. 开始对话

</Steps>

## 可用的 Anthropic 模型

Jan 已自动包含 Anthropic 的可用模型。如需使用 **Jan** 中未列出的特定 Anthropic 模型，请遵循[添加云端模型](/docs/manage-models#add-models-1)的说明：

- 查看 [Anthropic 模型列表](https://docs.anthropic.com/claude/docs/models-overview)中的可用模型
- `id` 属性必须与列表中的模型名称匹配。例如 `claude-opus-4@20250514`、`claude-sonnet-4@20250514` 或 `claude-3-5-haiku@20241022`

## 故障排除

常见问题及解决方案：

**1. API 密钥问题**

- 确认 API 密钥正确且未过期
- 检查 Anthropic 账户是否已设置账单
- 确保您有权访问尝试使用的模型

**2. 连接问题**

- 检查网络连接
- 验证 Anthropic 系统状态
- 查看 [Jan 日志](/docs/troubleshooting#how-to-get-error-logs)中的错误信息

**3. 模型不可用**

- 确认 API 密钥具有该模型的访问权限
- 检查是否使用了正确的模型 ID
- 验证 Anthropic 账户具备必要权限
