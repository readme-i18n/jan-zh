# Hugging Face

Jan 支持通过两种方式接入 Hugging Face 模型：全新的 **HF Router**（推荐）和 **Inference Endpoints**。两种方式均需配置 Hugging Face 令牌并**设置付费账户**。

![HuggingFace Inference Providers](../_assets/hf_providers.png)

## 选项一：HF Router（推荐方案）

HF Router 通过单一端点提供来自多个供应商（Replicate、Together AI、SambaNova、Fireworks、Cohere 等）的模型访问能力。

<Steps>

### 步骤 1：获取您的 HF 令牌

访问 [Hugging Face 设置 > 访问令牌](https://huggingface.co/settings/tokens) 并创建令牌。请确保您的账户已设置账单信息。

### 步骤 2：配置 Jan

1. 前往 **设置** > **模型提供商** > **HuggingFace**
2. 输入您的 HF 令牌
3. 使用此 URL: `https://router.huggingface.co/v1`

![Jan HF 设置](../_assets/hf_jan_setup.png)

您可以在[此处](https://huggingface.co/docs/inference-providers/index)了解更多关于 HF 路由器的信息。

### 步骤 3：开始使用模型

Jan 预置了三个 HF 路由器模型。选择其中一个即可立即开始对话。

</Steps>

<Callout type='info'>
HF 路由器会自动将您的请求路由至每个模型的最佳可用提供商，让您无需管理独立端点即可访问多种模型。
</Callout>

## 选项 2：HF 推理端点

如需对特定模型和部署配置进行更精细控制，您可以使用 Hugging Face 推理端点。

<Steps>

### 步骤 1：访问 HuggingFace 模型中心

登录后访问 [Hugging Face 模型中心](https://huggingface.co/models)，选择您要使用的模型。

![HuggingFace 模型中心](../_assets/hf_hub.png)

### 步骤 2：配置 HF 推理终端并部署

选定模型后，点击 **Deploy** 按钮选择部署方式。本示例将选择 HF Inference Endpoints。

![HuggingFace 部署界面](../_assets/hf_jan_nano.png)
<br/>

进入部署设置页面后，本示例保持 GPU 标签页的默认配置，点击 **Create Endpoint**。

![HuggingFace 部署设置](../_assets/hf_jan_nano_2.png)
<br/>

终端准备就绪后，在 **Test your endpoint** 标签页进行功能测试。

![HuggingFace 终端测试](../_assets/hf_jan_nano_3.png)
<br/>

收到响应后，点击 **Copy** 复制终端 URL 和 API 密钥。

<Callout type='info'>
  部署模型需登录 HuggingFace Inference Endpoints 并绑定信用卡。
</Callout>

### 步骤 3：配置 Jan

若没有 API 密钥，可通过 **Settings** > **Access Tokens** [此处](https://huggingface.co/settings/tokens) 创建。复制令牌后，在 Jan 的 **Settings** > **Model Providers** > **HuggingFace** 处添加终端 URL 和密钥。

![获取令牌](../_assets/hf_jan_nano_5.png)
<br/>

**3.2 HF 终端 URL 配置**

现在您可以在任意聊天会话中使用该模型。

如需了解如何搭配 MCP 使用 Jan Nano，请查阅[本指南](../jan-models/jan-nano-32)。

</Steps>

## 故障排除

常见问题及解决方案：

**1. 已启动聊天但模型无响应**

- 确认您的API_KEY/HF_TOKEN正确且未过期
- 确保您的HF账户已设置账单信息
- 对于推理终端节点：确保您尝试使用的模型已重新运行，因为一段时间后它们会进入空闲状态以避免未使用时产生费用

![运行中的模型](../_assets/hf_jan_nano_9.png)

**2. 连接问题**

- 检查您的网络连接
- 查看Hugging Face系统状态
- 在[Jan的日志](/docs/troubleshooting#how-to-get-error-logs)中查找错误信息

**3. 模型不可用**

- 确认您的API密钥有访问该模型的权限
- 检查是否使用了正确的模型ID
- 验证您的Hugging Face账户具备必要权限
