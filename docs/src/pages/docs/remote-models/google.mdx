# Google

Jan 支持 [Google](https://ai.google/get-started/our-models/) API 集成，允许您通过 Jan 界面使用 Google 模型（如 Gemini 系列）。

## 将 Google API 与 Jan 集成

<Steps>
### 步骤 1：获取 API 密钥
1. 访问 [Google AI Studio](https://aistudio.google.com/app/apikey) 并登录
2. 创建并复制新的 API 密钥或复制现有密钥

<Callout type='info'>
确保您的 API 密钥有足够的额度
</Callout>

### 步骤 2：配置 Jan

1. 导航至 **设置** 页面 (<Settings width={16} height={16} style={{display:"inline"}}/>)
2. 在 **模型提供商** 下选择 **Gemini**
3. 输入您的 **API 密钥**

<br/>
![Google](../_assets/google.png)
<br/>

### 步骤 3：开始使用 Google 模型

1. 进入任意现有 **聊天** 或创建新聊天
2. 从 **模型选择器** 中选择 Gemini 模型
3. 开始对话
</Steps>

## 可用的 Google 模型

Jan 自动包含 Google 的可用模型（如 Gemini 系列）。如果您想使用 **Jan** 中找不到的特定 Gemini 模型，请按照 [添加云端模型](/docs/manage-models#add-models-1) 中的说明操作：

- 可用的模型列表请查看 [Google Models](https://ai.google.dev/gemini-api/docs/models/gemini)
- `id` 属性必须与列表中的模型名称匹配，例如 `gemini-1.5-pro` 或 `gemini-2.0-flash-lite-preview`

## 故障排除

常见问题及解决方案：

**1. API 密钥问题**

- 确认您的 API 密钥正确且未过期
- 检查您的 Google 账户是否设置了账单
- 确保您有权访问尝试使用的模型

**2. 连接问题**

- 检查您的网络连接
- 查看 [Gemini 系统状态](https://www.google.com/appsstatus/dashboard/)
- 在 [Jan 的日志](/docs/troubleshooting#how-to-get-error-logs) 中查找错误信息

**3. 模型不可用**

- 确认您的 API 密钥有权访问该模型
- 检查是否使用了正确的模型 ID
- 验证您的 Google 账户是否具备必要权限
