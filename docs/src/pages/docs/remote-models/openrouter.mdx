# OpenRouter

## 将 OpenRouter 与 Jan 集成

[OpenRouter](https://openrouter.ai/) 是一个聚合AI模型API的工具，通过统一API提供对所有模型的访问。开发者可以使用该API与LLM、生成式图像模型甚至生成3D对象的模型进行交互，且价格具有竞争力。

Jan 支持 OpenRouter API，让您可以使用来自不同供应商（Anthropic、Google、Meta等）的模型，帮助您免去从所有喜爱的供应商处获取API的麻烦。

OpenRouter 甚至还提供一些免费模型！🙌

## 将 OpenRouter 与 Jan 集成

<Steps>

### 步骤 1：获取 API 密钥
1. 访问 [OpenRouter](https://openrouter.ai/keys) 并登录
2. 创建并复制新的 API 密钥，或复制现有密钥

<Callout type='info'>
请确保您的 API 密钥有足够余额。OpenRouter 余额可在所有可用模型间通用。
</Callout>

### 步骤 2：配置 Jan

1. 进入 **设置** 页面 (<Settings width={16} height={16} style={{display:"inline"}}/>)
2. 在 **模型供应商** 下选择 **OpenRouter**
3. 输入您的 **API 密钥**

<br/>
![OpenRouter](../_assets/openrouter.png)
<br/>

### 步骤 3：开始使用 OpenRouter 模型

1. 选择任意现有 **聊天** 或创建新对话
2. 从 OpenRouter 下的 **模型选择器** 中选取任意模型
3. 开始对话
</Steps>

## 通过 OpenRouter 可用的模型

Jan 会自动使用您 OpenRouter 账户的默认可用模型。如需自定义配置：

**模型字段设置：**

- 留空则使用账户默认模型
- 使用格式指定模型：`组织名称/模型名称`
- 可用选项参见 [OpenRouter 模型参考](https://openrouter.ai/models)

**模型 ID 示例：**

- Claude 4 Opus: `anthropic/claude-opus-4`
- Google Gemini 2.5 Pro: `google/gemini-2.5-pro-preview`
- DeepSeek R1 最新版: `deepseek/deepseek-r1-0528`

## 故障排除

常见问题及解决方案：

**1. API 密钥问题**

- 确认您的 API 密钥正确且未过期
- 检查 OpenRouter 账户是否有足够额度
- 确保您有权访问正在尝试使用的模型

**2. 连接问题**

- 检查网络连接
- 查看 OpenRouter 的[系统状态](https://status.openrouter.ai)
- 在 [Jan 的日志](/docs/troubleshooting#how-to-get-error-logs)中查找错误信息

**3. 模型不可用**

- 确认该模型目前在 OpenRouter 上可用
- 检查是否使用了正确的模型 ID 格式
- 验证模型提供商当前是否正常运行
