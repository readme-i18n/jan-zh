# OpenAI

Jan 支持大多数 [OpenAI](https://openai.com/) 以及众多 OpenAI 兼容的 API，使您可以通过 Jan 的界面使用所有 OpenAI 模型（GPT-4o、o3 甚至来自 Together AI、DeepSeek、Fireworks 等平台的模型）。

## 将 OpenAI API 与 Jan 集成

<Steps>

### 步骤 1：获取 API 密钥
1. 访问 [OpenAI 平台](https://platform.openai.com/api-keys) 并登录
2. 创建并复制新的 API 密钥或复制现有密钥

<Callout type='info'>
确保您的 API 密钥有足够的额度
</Callout>

### 步骤 2：配置 Jan

1. 导航至设置页面 (<Settings width={16} height={16} style={{display:"inline"}}/>)
2. 在远程引擎下选择 OpenAI
3. 输入您的 API 密钥

<br/>
![OpenAI](../_assets/openai.png)
<br/>

### 步骤 3：开始使用 OpenAI 模型

在任何现有会话中或创建新会话
从模型选择器中选择 OpenAI 模型
开始聊天

</Steps>

## 可用的 OpenAI 模型

Jan 已自动包含流行的 OpenAI 模型。如需使用 Jan 中未提供的特定模型，请按照[添加云端模型](/docs/manage-models#add-models-1)的说明操作：

- 查看 [OpenAI 平台](https://platform.openai.com/docs/models/overview)上的可用模型列表
- id 属性必须与列表中的模型名称匹配。例如，若需使用 [GPT-4.5](https://platform.openai.com/docs/models/)，必须将 id 属性设置为对应的值

## 故障排除

常见问题及解决方案：

1. API 密钥问题

- 确认 API 密钥正确且未过期
- 检查 OpenAI 账户是否已设置账单
- 确保您有权访问尝试使用的模型

2. 连接问题

- 检查网络连接
- 查看 OpenAI 的[系统状态](https://status.openai.com)
- 在 [Jan 日志](/docs/troubleshooting#how-to-get-error-logs)中查找错误信息

3. 模型不可用

- 确认 API 密钥具有该模型的访问权限
- 检查是否使用了正确的模型 ID
- 验证 OpenAI 账户是否具备必要权限
