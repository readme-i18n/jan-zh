# Groq

Jan 支持 [Groq](https://groq.com/) API 集成，允许您通过 Jan 的界面使用 Groq 的高性能 LLM 模型（包括 LLaMA 2、Mixtral 等）。

## 将 Groq API 集成到 Jan

<Steps>
### 步骤 1：获取 API 密钥
1. 访问 [Groq 控制台](https://console.groq.com/keys) 并登录
2. 创建并复制新的 API 密钥，或复制现有密钥

<Callout type='info'>
请确保您的 API 密钥有足够的额度
</Callout>

### 步骤 2：配置 Jan

1. 进入 **设置** (<Settings width={16} height={16} style={{display:"inline"}}/>)
2. 在 **模型提供商** 下选择 **Groq**
3. 输入您的 **API 密钥**

<br/>
![Groq](../_assets/groq.png)
<br/>


### 步骤 3：开始使用 Groq 模型

1. 进入任意现有 **聊天** 或创建新聊天
2. 从 **模型选择器** 中选择 Groq 模型
3. 开始对话
</Steps>

## 通过 Groq 可用的模型

Jan 会自动包含 Groq 的可用模型。如果您想使用某个特定的 Groq 模型但在 **Jan** 中找不到，请按照 [添加云端模型](/docs/manage-models#add-models-1) 中的说明操作：

- 可用的模型列表请参阅 [Groq Documentation](https://console.groq.com/docs/models)
- `id` 属性必须与列表中的模型名称匹配。例如，若要使用 Llama3.3 70B，必须将 `id` 属性设为 `llama-3.3-70b-versatile`

## 故障排除

常见问题及解决方案：

**1. API 密钥问题**

- 确认您的 API 密钥正确且未过期
- 检查 Groq 账户是否已设置账单信息
- 确保您有权访问尝试使用的模型

**2. 连接问题**

- 检查网络连接状态
- 查看 Groq 系统状态是否正常
- 在 [Jan 的日志](/docs/troubleshooting#how-to-get-error-logs) 中查找错误信息

**3. 模型不可用**

- 确认您的 API 密钥具有模型访问权限
- 检查是否使用了正确的模型 ID
- 验证您的 Groq 账户具备必要权限
