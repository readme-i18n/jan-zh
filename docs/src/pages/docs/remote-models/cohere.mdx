# Cohere

Jan 支持 [Cohere](https://cohere.com/) API 集成，允许您通过 Jan 的界面使用 Cohere 的模型（Command、Command-R 等）。

## 将 Cohere API 与 Jan 集成

<Steps>

### 步骤 1：获取 API 密钥
1. 访问 [Cohere 控制面板](https://dashboard.cohere.com/api-keys) 并登录
2. 创建新的 API 密钥 和/或 复制现有密钥

<Callout type='info'>
请确保您的 API 密钥有足够的额度。
</Callout>

### 步骤 2：配置 Jan

1. 进入 **设置** (<Settings width={16} height={16} style={{display:"inline"}}/>)
2. 在 **模型提供商** 下选择 **Cohere**
3. 输入您的 **API 密钥**

<br/>
![Cohere](../_assets/cohere.png)
<br/>

### 步骤 3：开始使用 Cohere 模型

1. 进入任意现有 **聊天** 或创建新聊天
2. 从 **模型选择器** 选项中选择 Cohere 模型
3. 开始对话
</Steps>

## 可用的 Cohere 模型

Jan 会自动包含 Cohere 的可用模型。如果您想使用在 **Jan** 中找不到的特定 Cohere 模型，请按照 [添加云端模型](/docs/manage-models) 中的说明操作：

- 可用模型列表请参阅 [Cohere Documentation](https://docs.cohere.com/v2/docs/models)
- `id` 属性必须与列表中的模型名称匹配，例如 `command-nightly` 或 `command-light`

## 故障排除

常见问题及解决方案：

**1. API 密钥问题**

- 确认您的 API 密钥正确且未过期
- 检查您的 Cohere 账户是否已设置账单信息
- 确保您有权访问正在尝试使用的模型

**2. 连接问题**

- 检查您的网络连接
- 查看 Cohere 的 [系统状态](https://status.cohere.com/)
- 在 [Jan 的日志](/docs/troubleshooting#how-to-get-error-logs) 中查找错误信息

**3. 模型不可用**

- 确认您的 API 密钥有权访问该模型
- 检查您是否使用了正确的模型 ID
- 验证您的 Cohere 账户是否具备必要权限
