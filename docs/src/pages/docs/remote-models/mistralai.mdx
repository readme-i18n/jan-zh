# Mistral AI

Jan支持通过[Mistral AI](https://mistral.ai/) API提供的所有模型，您可以通过Jan界面使用Mistral的强大模型（包括Mistral Large、Mistral Medium、Mistral Small等）。

## 将Mistral AI集成到Jan

<Steps>

### 步骤1：获取API密钥
1. 访问[Mistral AI平台](https://console.mistral.ai/api-keys/)并登录
2. 创建并复制新的API密钥，或复制现有密钥

<Callout type='info'>
请确保您的API密钥有足够的额度
</Callout>

### 步骤2：配置Jan

1. 进入**设置**页面 (<Settings width={16} height={16} style={{display:"inline"}}/>)
2. 在**模型提供商**下选择**Mistral AI**
3. 输入您的**API密钥**

<br/>
![Mistral](../_assets/mistralai.png)
<br/>

### 步骤3：开始使用Mistral模型

1. 打开任意现有**聊天**或创建新聊天
2. 从**模型选择器**中选择Mistral模型
3. 开始对话
</Steps>

## 可用的Mistral模型

Jan 已自动包含 Mistral 提供的可用模型。如需使用在 **Jan** 中未找到的特定 Mistral 模型，请按照[添加云端模型](/docs/manage-models#add-models-1)的说明操作：

- 查看[Mistral AI 文档](https://docs.mistral.ai/platform/endpoints)中的可用模型列表
- `id`属性必须与列表中的模型名称完全匹配。例如要使用 Mistral Large 模型，必须将`id`属性设为`mistral-large-latest`

## 故障排除

常见问题及解决方案：

**1. API 密钥问题**

- 确认您的 API 密钥正确且未过期
- 检查 Mistral AI 账户是否已设置账单信息
- 确保您有权访问目标模型

**2. 连接问题**

- 检查网络连接状态
- 查看[Mistral AI 系统状态](https://status.mistral.ai/)
- 在[Jan 的日志文件](/docs/troubleshooting#how-to-get-error-logs)中查找错误信息

**3. 模型不可用**

- 确认 API 密钥具有模型访问权限
- 检查是否使用了正确的模型 ID
- 验证 Mistral AI 账户具备必要权限
