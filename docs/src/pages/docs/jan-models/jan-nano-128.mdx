# Jan-Nano-128k

> 通过扩展上下文理解能力推动深度研究

Jan-Nano-128k 在紧凑型语言模型领域实现了显著突破。基于 Jan-Nano-32k 的成功基础，该增强版本具备原生 128k 上下文窗口，可在不损失性能的前提下实现更深层次、更全面的研究能力，避免了传统上下文扩展方法常见的性能下降问题。

您可以通过 [Menlo Models 页面](https://huggingface.co/Menlo)查看并下载我们所有的模型。

**核心改进：**

- 🔍 深度研究：扩展的上下文窗口可处理完整的研究论文、长篇文档和复杂的多轮对话
- ⚡ 原生 128k 窗口：专为高效处理长上下文设计，在整个上下文范围内保持性能稳定
- 📈 性能提升：与传统上下文扩展方法不同，Jan-Nano-128k 在长上下文场景下仍能保持一致的性能表现

该模型完全兼容模型上下文协议 (MCP) 服务器，同时显著扩展了单次会话中可处理的研究任务范围。

## 为什么选择 Jan-Nano-128k？

大多数小型模型在8-32k tokens时会遇到性能瓶颈。而Jan-Nano-128k通过原生支持的128k上下文窗口突破了这一限制——相当于能同时处理约300页文本或一整部小说的信息量。

与YaRN或PI等方法通过改造模型强行突破限制导致性能下降不同，Jan-Nano-128k是从底层架构上为128k上下文重新设计的。其结果是展现出逆向缩放特性：随着上下文增长性能反而提升，在1k到128k tokens范围内保持稳定的准确性，因为模型能利用更多信息进行综合推理。

<Callout type="info">
**位置插值法(PI):** 通过缩放位置索引使其适配原始上下文窗口来扩展模型上下文的方法。例如要将4k模型扩展到32k，PI会将32k位置压缩至原始4k范围，具体做法是将每个位置除以8。

**YaRN(另一种RoPE扩展方法):** 更复杂的上下文扩展方法，能保留高频出现的token同时选择性缩放其他token。YaRN将位置嵌入划分为不同频率组并对每组应用不同缩放因子，相比PI能实现更高效的训练和更优的性能。

关键区别在于：PI对所有维度应用统一缩放，而YaRN基于频率分析进行针对性插值——保留对区分邻近token至关重要的高频信息，同时对低频信息进行更激进的插值处理。
</Callout>

**解锁的应用场景:**

- **学术研究**: 同时从50+篇论文中提取关键发现  
- **法律领域**: 在千页合同中精确定位相关条款
- **代码分析**: 在大型代码库中追踪特定函数
- **商业智能**: 从季度财务数据中提炼洞察
- **内容创作**: 保持书籍长度输出的叙事连贯性

**MCP 使用说明：** Jan-Nano-128k 不进行记忆存储，而是执行智能编排。通过 MCP 集成，它化身为研究指挥家——能同时调取数十个数据源，将所有内容保持在活跃内存中，精准提取所需信息，并在马拉松式研究会话中完成成果合成。其核心价值不在于逐字理解，而在于实现海量数据中的精准定位。

2. **获取 Jan-Nano-128k 模型**
3. **启用 MCP**（serper 或 exa MCP 与 Jan-Nano-128k 适配性最佳）
4. **开始研究**

### 使用方法

通过 VLLM 部署：

```bash
vllm serve Menlo/Jan-nano-128k \
 --host 0.0.0.0 \
 --port 1234 \
 --enable-auto-tool-choice \
 --tool-call-parser hermes \
 --rope-scaling '{"rope_type":"yarn","factor":3.2,"original_max_position_embeddings":40960}' --max-model-len 131072
```

或使用 `llama.cpp` 的 `llama-server`：

```bash
llama-server ... --rope-scaling yarn --rope-scale 3.2 --yarn-orig-ctx 40960
```

**注意：** 聊天模板已集成在分词器中。故障排查请下载 [Non-think 聊天模板](https://qwen.readthedocs.io/en/latest/_downloads/c101120b5bebcc2f12ec504fc93a965e/qwen3_nonthinking.jinja)。

### 硬件要求

- **最低配置**: 16GB 内存（适用于 Q4 量化）
- **推荐配置**: 24GB 内存（适用于 Q8 量化）
- **最佳配置**: 32GB+ 内存（适用于全精度模式）
