# Jan Nano

![Jan Nano](../_assets/jan-nano0.png)

## 为什么选择 Jan Nano？

大多数语言模型都面临一个根本性的权衡：强大的能力需要大量计算资源。Jan Nano 通过专注的设计理念打破了这一限制——它不追求无所不知，而是擅长于知晓如何找到任何信息。

## 什么是 Jan Nano？

Jan Nano 是一个紧凑的 40 亿参数语言模型，专为深度研究任务设计和训练。该模型已优化以与模型上下文协议（MCP）服务器无缝协作，实现与各类研究工具和数据源的高效集成。

该模型及其不同变体版本均得到 Jan 的完整支持。

<Callout type="info">
  使用 Jan-Nano 需要通过 MCP 连接搜索引擎。您可在**设置**选项卡的**高级设置**中启用 MCP 功能。
</Callout>

## 系统要求

- 最低要求：
  - 8GB 内存（使用 iQ4_XS 量化版本）
  - 12GB 显存（用于 Q8 量化版本）
  - 兼容 CUDA 的 GPU
- 推荐配置：
  - 16GB 以上内存
  - 16GB 以上显存
  - 最新 CUDA 驱动
  - RTX 30/40 系列或更新显卡

## 使用 Jan-Nano-32k

**第一步**  
从[这里](https://jan.ai/docs/desktop/)下载Jan应用。

**第二步**  
进入Hub标签页，搜索Jan-Nano-Gguf，点击下载按钮选择最适合您系统配置的模型尺寸。

![Jan Nano](../_assets/jan-nano1.png)

**第三步**  
前往**设置** > **模型提供商** > **Llama.cpp**，点击铅笔图标并为Jan-Nano-Gguf启用工具使用功能。

**第四步**  
要充分发挥Jan-Nano的全部功能，需启用MCP支持。我们将结合Serper的API使用。您可以从[这里](https://serper.dev/)获取免费API密钥，注册后系统会立即生成密钥。

**第五步**  
通过**设置** > **MCP服务器**标签页将Serper MCP添加到Jan中。

![Serper MCP](../_assets/serper-mcp.png)

**第六步**  
新建聊天会话，让Jan-Nano为您执行网络搜索。

![Jan Nano](../_assets/jan-nano-demo.gif)

## 常见问题

- 推荐的 GGUF 量化版本有哪些？
  - 追求最佳性能推荐使用 Q8 GGUF
  - 显存严重受限时建议选择 iQ4_XS GGUF
  - 应避免使用 Q4_0 和 Q4_K_M，因其存在显著性能下降

- 8GB 内存的笔记本电脑能否运行？
  - 可以，但需选用推荐量化版本（iQ4_XS）
  - 注意 Q4 量化版本可能限制性能表现

- 训练成本是多少？
  - 训练在内部 A6000 集群完成
  - 使用 H200 在 RunPod 上预估成本低于 100 美元
  - 硬件配置：
    - 训练代码使用 8 块 A6000
    - 推理服务使用 4 块 A6000 (vllm 服务器)

- 推荐使用什么前端界面？
  - Jan Beta（推荐）- 极简且精致的界面
  - 下载链接：https://jan.ai/docs/desktop/beta

- 在 LM Studio 遇到 Jinja 错误？
  - 改用其他 LM Studio 兼容模型的 Qwen3 模板
  - 禁用"thinking"功能并添加必需的系统提示
  - 后续 GGUF 版本将修复此问题
- Jan 出现模型加载问题？
  - 使用最新测试版：Jan-beta_0.5.18-rc6-beta
  - 确保 GPU 具备正确的 CUDA 支持
  - 检查显存是否符合所选量化版本要求
