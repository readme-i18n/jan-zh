# 故障排除

## 获取帮助：错误日志

当 Jan 运行异常时，错误日志有助于定位问题。以下是获取日志的方法：

### 快速访问日志

**在 Jan 界面中：**

1. 在页脚查找 **System Monitor**
2. 点击 **App Log**

![应用日志](./_assets/trouble-shooting-02.png)

**通过终端：**

```bash
# macOS/Linux
tail -n 50 ~/Library/Application\ Support/Jan/data/logs/app.log

# Windows  
type %APPDATA%\Jan\data\logs\app.log
```

<Callout type="warning">
分享日志前请移除所有个人信息。我们仅保留24小时的日志记录。
</Callout>

## 常见问题及解决方案

### Jan 无法启动（安装损坏）

如果安装后 Jan 卡住或无法正常启动：

<Tabs items={['macOS', 'Windows', 'Linux']}>
<Tabs.Tab>

**Clean Reinstall Steps:**

1. **Uninstall Jan** from Applications folder

2. **Delete all Jan data:**
```bash
rm -rf ~/Library/Application\ Support/Jan
```

3. **Kill any background processes** (for versions before 0.4.2):
```bash
ps aux | grep nitro
# Find process IDs and kill them:
kill -9 <PID>
```

4. **Download fresh copy** from [jan.ai](/download)

</Tabs.Tab>
<Tabs.Tab>

**Clean Reinstall Steps:**

1. **Uninstall Jan** via Control Panel

2. **Delete application data:**
```cmd
cd C:\Users\%USERNAME%\AppData\Roaming
rmdir /S Jan
```

3. **Kill background processes** (for versions before 0.4.2):
```cmd
# Find nitro processes
tasklist | findstr "nitro"
# Kill them by PID
taskkill /F /PID <PID>
```

4. **Download fresh copy** from [jan.ai](/download)

</Tabs.Tab>
<Tabs.Tab>

**Clean Reinstall Steps:**

1. **Uninstall Jan:**
```bash
# For Debian/Ubuntu
sudo apt-get remove jan

# For AppImage - just delete the file
```

2. **Delete application data:**
```bash
# Default location
rm -rf ~/.config/Jan

# Or custom location
rm -rf $XDG_CONFIG_HOME/Jan
```

3. **Kill background processes** (for versions before 0.4.2):
```bash
ps aux | grep nitro
kill -9 <PID>
```

4. **Download fresh copy** from [jan.ai](/download)

### NVIDIA GPU 无法工作

如果 Jan 未使用您的 NVIDIA 显卡进行加速：

<Steps>

### 步骤 1：检查硬件配置

**验证 GPU 识别情况：**

*Windows:* 右键桌面 → NVIDIA 控制面板，或检查设备管理器 → 显示适配器

*Linux:* 运行 `lspci | grep -i nvidia`

**安装必备软件：**

**NVIDIA 驱动程序 (470.63.01 或更新版本)：**
1. 从 [nvidia.com/drivers](https://www.nvidia.com/drivers/) 下载
2. 测试：在终端运行 `nvidia-smi`

**CUDA 工具包 (11.7 或更新版本)：**
1. 从 [CUDA Downloads](https://developer.nvidia.com/cuda-downloads) 下载
2. 测试：运行 `nvcc --version`

**Linux 额外要求：**
```bash
# 安装必备软件包
sudo apt update && sudo apt install gcc-11 g++-11 cpp-11

# 设置 CUDA 环境
export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/usr/local/cuda/lib64
```

### 步骤 2：在 Jan 中启用 GPU 加速

1. 打开 **设置** > **硬件**
2. 开启 **GPU 加速**
3. 检查 **系统监视器** (底部状态栏) 确认 GPU 已被识别

![硬件](./_assets/trouble-shooting-01.png)

### 步骤 3：验证配置

1. 进入 **设置** > **高级设置** > **数据文件夹**
2. 打开 `settings.json` 文件
3. 检查以下设置：

```json
{
  "run_mode": "gpu",          // 应为 "gpu"
  "nvidia_driver": {
    "exist": true,            // 应为 true
    "version": "531.18"
  },
  "cuda": {
    "exist": true,            // 应为 true
    "version": "12"
  },
  "gpus": [
    {
      "id": "0",
      "vram": "12282"         // 显存容量 (单位 MB)
    }
  ]
}
```

### 步骤 4：重启 Jan

关闭并重新启动 Jan 以应用更改。

</Steps>

#### 已验证可用的配置方案

**桌面系统：**

- Windows 11 + RTX 4070Ti + CUDA 12.2 + 驱动 531.18
- Ubuntu 22.04 + RTX 4070Ti + CUDA 12.2 + 驱动 545

**虚拟机环境：**

- Proxmox 上的 Ubuntu + GTX 1660Ti + CUDA 12.1 + 驱动 535

<Callout type="info">
桌面安装方案性能优于虚拟机。虚拟机需正确配置 GPU 直通功能。
</Callout>

### "获取失败"或"出现异常"错误处理

当模型无响应或显示以下错误时：

**1. 检查系统要求**

- **内存：** 使用不超过可用内存80%的模型
  - 8GB系统：使用小于6GB的模型
  - 16GB系统：使用小于13GB的模型
- **硬件：** 确认系统符合[最低要求](/docs/troubleshooting#step-1-verify-hardware-and-system-requirements)

**2. 调整模型设置**

- 在聊天侧边栏打开模型设置
- 降低 **GPU层数(ngl)** 参数
- 从较低值开始逐步增加

**3. 检查端口冲突**
若日志显示"绑定地址失败"：

```bash
# Check if ports are in use
# macOS/Linux
netstat -an | grep 1337

# Windows
netstat -ano | find "1337"
```

**Jan默认端口：**

- API服务端：`1337`
- 文档服务：`3001`

**4. 尝试恢复出厂设置**

1. 进入**设置** > **高级设置**
2. 点击"恢复出厂设置"下的**重置**按钮

<Callout type="warning">
此操作将删除所有聊天记录、模型及设置。
</Callout>

**5. 完全重新安装**
如果问题仍然存在，请执行完全干净的安装（参考上文"Jan无法启动"部分）。

### 权限拒绝错误

如果安装过程中出现权限错误：

```bash
# Fix npm permissions (macOS/Linux)
sudo chown -R $(whoami) ~/.npm

# Windows - run as administrator
```

### OpenAI API问题（"意外令牌"错误）

针对OpenAI连接问题：

**1. 验证API密钥**

- 从[OpenAI平台](https://platform.openai.com/)获取有效密钥
- 确保账户有足够余额和权限

**2. 检查地区访问限制**

- 某些地区存在API限制
- 尝试使用支持地区的VPN连接
- 测试到OpenAI端点的网络连通性

### 性能问题

**模型运行缓慢：**

- 启用GPU加速（参考NVIDIA部分）
- 根据硬件选择适当规模的模型
- 关闭其他内存密集型应用
- 通过任务管理器/活动监视器检查资源占用

**内存占用过高：**

- 切换至更小的模型变体
- 在模型设置中减少上下文长度
- 在引擎设置中启用模型卸载

**频繁崩溃：**

- 更新显卡驱动
- 检查系统温度
- 如果使用GPU加速，减少GPU层数
- 确保电源供应充足（台式机系统）
