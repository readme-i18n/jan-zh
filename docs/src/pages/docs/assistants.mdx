# 助手管理

Jan 允许您为模型配置特定指令集而无需重复输入。我们将这些加载了您指令的模型称为"助手"。每个助手都可以拥有独立的配置集，用于指导AI模型的行为方式和响应输入的方式。您可以在助手标签页中添加、编辑或删除助手，并自定义其指令和设置。

![助手管理页面截图，可查看、添加、编辑或删除助手。每个助手都有名称、描述，并能针对不同任务进行定制。](./_assets/assistants-ui-overview.png)

查找助手标签页的方法：

1. 打开Jan并查看左侧边栏
2. 点击**Assistants**标签页（参见上方截图高亮部分）
3. 主面板将显示您当前所有的助手

## 助手管理操作

- **添加新助手**：点击助手面板中的 `+` 按钮，根据您的指令创建新助手。
- **编辑助手**：点击任意助手卡片上的铅笔图标（✏️）可更新其名称、描述或指令。
- **删除助手**：点击垃圾桶图标（🗑️）可移除不再需要的助手。

## 自定义助手指令

每个助手都可以拥有专属的行为指引指令集。例如：

```
Act as a software engineering mentor focused on Python and JavaScript.
Provide detailed explanations with code examples when relevant.
Use markdown formatting for code blocks.
```

或：

```
Respond in a casual, friendly tone. Keep explanations brief and use simple language.
Provide examples when explaining complex topics.
```

或：

```
Respond in a casual, friendly tone. Keep explanations brief and use simple language.
Provide examples when explaining complex topics.
```

## 最佳实践

- 明确指定每个助手的行为要求
- 包含格式、语气或风格的偏好设置
- 提供示例以提高模型响应符合度
- 为不同任务分配专用助手（如翻译、旅行规划、财务建议）

## 在聊天中切换与管理助手

您可以通过聊天界面顶部的助手下拉菜单快速切换助手，或直接进行创建/编辑操作：

![助手下拉菜单](./_assets/assistant-dropdown-updated.png)

- 点击聊天界面顶部的助手名称（如"旅行规划师"）展开下拉菜单
- 下拉菜单会列出所有助手，点击任意选项即可在当前会话中切换
- 如需新建助手，选择菜单底部的 **创建助手** 将打开添加助手对话框：

![添加助手对话框](./_assets/assistant-add-dialog.png)

- 要编辑现有助手，请点击下拉菜单中名称旁边的齿轮(⚙️)图标。这将打开编辑助手对话框：

![编辑助手对话框](./_assets/assistant-edit-dialog.png)

### 添加/编辑助手对话框

- 为您的助手设置（可选）表情符号和名称
- 可选择添加描述
- 输入详细指令以指导助手行为
- 根据需要调整预定义参数（如Temperature、Top P等）或添加自定义参数
- 点击**保存**应用更改

该工作流程让您能在聊天时无缝管理和切换助手，实时定制Jan以满足您的需求。
