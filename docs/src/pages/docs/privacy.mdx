# 隐私政策

Jan 是专属于您的 AI。以下是我们的数据处理方式。

<Callout>
完整隐私政策详见[此处](/docs/privacy-policy)，若您需要查阅正式条款。
</Callout>

<Callout type="info">
未经明确许可绝不收集数据。以童子军荣誉起誓。
</Callout>

首次启动时将选择跟踪偏好。您可随时在设置中更改。

Jan **永不**窥探您的聊天记录、设置或模型选择。即便您主动请求也不会。

## 我们跟踪的数据（需获得许可）

仅收集基础应用使用数据以改进 Jan。仅此而已。

### 产品分析

获得授权后，我们统计：

- **活跃用户**：每日使用 Jan 的爱好者
- **留存率**：长期使用的用户群体

所有数据关联随机 ID —— 与您个人无关。您的聊天内容始终私有。

## 我们绝不跟踪的内容

<Callout type="info">
Jan 严守边界。我们致力于保护您的隐私。
</Callout>

- 不监控聊天内容
- 不扫描文件内容
- 不追踪身份信息
- 不记录提示词
- 不监听对话过程
- 不跟踪模型选择

您的隐私数据始终私密

## 云端模型使用

云端模型(如GPT、Claude)需要读取您的消息才能工作。这属于您与模型服务商之间的直接交互 - Jan仅作为中介桥梁。本地模型则将所有数据保留在本地，杜绝任何外部窥探。

## 数据存储

[PostHog EU](https://posthog.com/eu)负责处理分析数据。所有服务器位于欧盟境内，完全符合GDPR规范，安全措施完备。详情参见其[GDPR文档](https://posthog.com/docs/privacy/gdpr-compliance)。
