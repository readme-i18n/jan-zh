# 设置

点击左下角 <Settings width={16} height={16} style={{display:"inline"}}/> 图标即可访问 Jan 的设置选项。

## AI 模型管理

所有模型选项位于 **设置** > **模型提供商**：

### 添加模型

**从 Hugging Face 获取：**

- 在搜索栏输入模型 ID（如 `microsoft/DialoGPT-medium`）
- **需要认证？** 部分模型需 Hugging Face 令牌 - 在 **设置 > 模型提供商 > Hugging Face 访问令牌** 处添加您的令牌

**从本地计算机导入：**

- 点击 **导入模型** 并选择计算机中的 GGUF 文件
- 支持任何已下载的兼容模型文件

### 管理现有模型

**启动模型：**

1. 打开新聊天窗口并选择目标模型
2. 或前往 **设置 > 模型提供商** 点击 **启动** 按钮

**移除模型：**

- 点击 **启动** 按钮旁的垃圾桶图标
- 根据提示确认删除操作

### Hugging Face 令牌设置

对于受限模型（如 Meta 的 Llama 系列）：

1. 从 [Hugging Face Tokens](https://huggingface.co/docs/hub/en/security-tokens) 获取您的令牌
2. 在 **设置 > 模型提供商 > Hugging Face** 处添加

## 模型配置（齿轮图标）

![模型设置](./_assets/trouble-shooting-04.png)

点击任意模型旁的齿轮图标可调整其行为：

**基础设置：**

- **上下文长度**：模型能记住的对话历史量
- **GPU 层数**：模型在显卡上运行的比例（数值越高速度越快，但占用更多显存）
- **温度系数**：控制创造性（0.1 = 专注，1.0 = 创意）

**高级控制：**

- **Top K & Top P**：微调模型选词策略（数值越低越专注）
- **Min P**：词语选择的最小概率阈值
- **重复惩罚**：防止模型过度自我重复
- **存在惩罚**：鼓励模型使用多样化词汇

<Callout type="info">
关于这些参数的详细说明，请参阅我们的[模型参数指南](/docs/model-parameters)。
</Callout>

## 硬件监控

在 **设置 > 硬件** 查看电脑性能：

- **CPU、内存、显卡**：实时使用率与规格参数
- **GPU 加速**：启用/禁用显卡加速
- **温度监控**：实时监测系统温度

![硬件监控](./_assets/hardware.png)

<Callout type="warning">
如果您的电脑发热严重，建议使用更小规模的模型或减少 GPU 层数。
</Callout>

## 个性化设置

### 视觉外观

在 **设置** > **外观** 中自定义 Jan 的显示效果：

- **主题**：选择浅色或深色模式
- **配色**：选择您偏好的色彩方案
- **代码高亮**：调整编程讨论中的语法着色

![外观设置](./_assets/settings-04.png)

### 写作辅助

**拼写检查**：Jan 可帮助识别消息中的输入错误。

![拼写检查](./_assets/settings-06.png)

## 隐私与数据控制

通过 **设置** > **隐私** 访问隐私选项：

### 使用分析

**默认：不收集数据**。所有内容都保留在您的设备上。

**可选：帮助改进 Jan**

- 开启 **分析** 以分享匿名使用模式
- 绝不共享对话内容或个人数据
- 可随时更改此设置

<Callout type="info">
查看我们（在您许可下）具体收集哪些数据，请参阅[隐私政策](/docs/privacy)。
</Callout>

![分析设置](./_assets/settings-07.png)

### 日志管理

**查看系统日志：**

- 日志有助于故障排查
- 点击文件夹图标可查看应用日志和系统日志
- 日志将在 24 小时后自动删除

![查看日志](./_assets/settings-08.png)

**清除日志：**

- 点击**清除**可立即移除所有日志文件
- 在共享电脑或故障排除前特别有用

<Callout type="warning">
清除日志操作不可撤销。
</Callout>

![清除日志](./_assets/settings-09.png)

### 数据文件夹管理

Jan 将所有数据以标准文件格式存储在您的本地计算机上。

**访问您的数据：**

- 点击文件夹图标打开 Jan 的数据目录
- 查找聊天记录、模型和设置文件
- 所有文件均可自由备份、移动或检查

![打开 Jan 数据文件夹](./_assets/settings-11.png)

**更改存储位置：**

1. 点击铅笔图标编辑数据文件夹路径
2. 选择一个空目录
3. 确认迁移（原文件夹保持不变）
4. 重启 Jan 完成更改

![编辑 Jan 数据文件夹](./_assets/settings-12.png)

<Callout type="info">
此操作会将数据复制到新位置 - 原始文件保持安全。
</Callout>

## 紧急选项

### 恢复出厂设置

**使用场景：** 仅作为其他解决方案无法修复的严重问题时的最后手段。

**功能说明：** 将 Jan 恢复至初始状态 - 删除所有数据。

**操作步骤：**

1. 点击"恢复出厂设置"下方的 **Reset** 按钮
2. 输入 **RESET** 确认您理解此操作将删除所有内容
3. 可选保留当前数据文件夹位置
4. 点击 **Reset Now**
5. 重新启动 Jan

![恢复出厂设置](./_assets/settings-17.png)

![重置确认](./_assets/settings-18.png)

<Callout type="error">
**此操作不可逆。** 所有聊天记录、下载的模型及设置将被永久删除。
</Callout>

**建议先尝试以下操作：**

- 重启 Jan
- 查阅[故障排除指南](./troubleshooting)
- 在[Discord](https://discord.gg/qSwXFx6Krr)寻求帮助

## 快速提示

**新用户建议：**

- 从默认设置开始使用
- 尝试多种模型以找到最佳方案
- 若配备显卡请启用GPU加速

**性能优化：**

- 实时监控硬件使用情况
- 根据显卡显存调整GPU层数
- 老旧硬件建议使用小型模型

**隐私保护：**

- 默认所有数据本地存储
- 检查数据文件夹查看具体存储内容
- 数据分析功能需手动启用
