# 模型管理

本指南将展示如何在Jan中添加、自定义和删除模型

## 本地模型

本地模型通过[Llama.cpp](https://github.com/ggerganov/llama.cpp)进行管理，这些模型采用GGUF格式。当您在本地运行它们时，会占用计算机内存(RAM)和处理器资源，因此请确保下载与您操作系统硬件规格相匹配的模型：

- [Mac](/docs/desktop/mac#compatibility)
- [Windows](/docs/desktop/windows#compatibility)
- [Linux](/docs/desktop/linux#compatibility)

### 添加模型

#### 1. 从Jan Hub下载（推荐）

最简单的方式是使用Jan内置的模型中心（该中心连接至[HuggingFace的模型库](https://huggingface.co/models)：

1. 进入**Hub**标签页
2. 浏览可用模型并点击任意模型查看详情
3. 选择符合您需求及硬件规格的模型
4. 在所选模型上点击**Download**按钮

<Callout type="info">
Jan 会根据您的系统配置，标注模型可能**在您的设备上运行缓慢**或**内存不足**的情况。
</Callout>

<br/>

![下载模型](./_assets/model-management-01.png)

#### 2. 从 [Hugging Face](https://huggingface.co/) 导入

您可以通过 Hugging Face 的直接链接下载模型：

**注意：** 部分模型需要 Hugging Face 访问令牌。导入前请前往**设置 > 模型供应商 > Hugging Face**输入您的令牌。

1. 访问 [Hugging Face 模型库](https://huggingface.co/models)
2. 找到目标模型，确保是适合您电脑的 GGUF 格式文件
3. 复制**模型 ID**（例如 TheBloke/Mistral-7B-v0.1-GGUF）
4. 在 Jan 的**Hub**页面搜索栏粘贴模型 ID
5. 选择您偏好的量化版本下载（如可选）

<br/>

#### 3. 导入本地文件

如果您的电脑已存有 GGUF 模型文件：

1. 在 Jan 中进入**设置 > 模型供应商 > Llama.cpp**
2. 点击**导入**并选择 GGUF 文件
3. 选择导入方式：

- **链接文件：** 创建模型文件的符号链接（节省空间）
  - **复制：** 在 Jan 目录生成文件副本

4. 点击**导入**完成操作（更多信息请查看 [Jan 数据文件夹](./data-folder) 章节）

<Callout type="warning">
您需要自行管理**模型配置**，使用风险自负。配置错误可能导致输出质量下降或产生意外结果。了解[模型配置详情](./model-parameters)。
</Callout>

#### 4. 手动设置

适用于希望在 Jan **Hub** 之外添加特定模型的高级用户：

<Steps>
##### 第一步：创建模型文件
1. 进入 [Jan 数据文件夹](./data-folder)
2. 打开 `models` 文件夹
3. 为您的模型创建一个新**文件夹**
4. 添加您的 `model.gguf` 文件
5. 添加包含配置的 `model.json` 文件。以下是 "TinyLlama Chat 1.1B Q4" 的示例：

```json
{
  "sources": [
    {
      "filename": "tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf",
      "url": "https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF/resolve/main/tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf"
    }
  ],
  "id": "tinyllama-1.1b",
  "object": "model",
  "name": "TinyLlama Chat 1.1B Q4",
  "version": "1.0",
  "description": "TinyLlama is a tiny model with only 1.1B. It's a good model for less powerful computers.",
  "format": "gguf",
  "settings": {
    "ctx_len": 4096,
    "prompt_template": "<|system|>\n{system_message}<|user|>\n{prompt}<|assistant|>",
    "llama_model_path": "tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf"
  },
  "parameters": {
    "temperature": 0.7,
    "top_p": 0.95,
    "stream": true,
    "max_tokens": 2048,
    "stop": [],
    "frequency_penalty": 0,
    "presence_penalty": 0
  },
  "metadata": {
    "author": "TinyLlama",
    "tags": [
      "Tiny",
      "Foundation Model"
    ],
    "size": 669000000
  },
  "engine": "nitro"
}
```
##### 第二步：修改模型参数

关键配置字段：
1. **Settings** 数组用于设置模型在计算机中的路径或位置、允许的上下文长度以及模型预期的聊天模板。
2. [**Parameters**](/docs/model-parameters) 是可调整的设置，影响模型的运行方式或数据处理。参数数组中的字段通常是通用的，可以跨不同模型使用。以下是模型参数的示例：

```json
"parameters":{
  "temperature": 0.7,
  "top_p": 0.95,
  "stream": true,
  "max_tokens": 4096,
  "frequency_penalty": 0,
  "presence_penalty": 0,
}
```
</Steps>

### 删除模型

1. 进入 **设置 > 模型供应商 > Llama.cpp**
2. 找到需要移除的模型
3. 点击模型旁的三个点 <EllipsisVertical width={16} height={16} style={{display:"inline"}}/> 图标并选择 **删除模型**

## 云端模型

<Callout type="info">
使用云端模型时请注意供应商相关的费用和速率限制。各云端模型供应商的详细指南请参见[此处](/docs/remote-models/anthropic)。
</Callout>

Jan 支持连接多种兼容 OpenAI API 的云端 AI 供应商，包括：OpenAI (GPT-4o, o3,...)、Anthropic (Claude)、Groq、Mistral 等。

1. 导航至 **设置** (<Settings width={16} height={16} style={{display:"inline"}}/>)
2. 在左侧边栏的 **模型供应商** 部分选择目标供应商（OpenAI、Anthropic 等）
3. 输入您的 API 密钥
4. 激活的云端模型将出现在 **聊天** 面板的模型选择器中

<br/>

![下载模型](./_assets/model-management-06.png)

<br/>

当您为 Anthropic 或 OpenAI 等供应商添加密钥后，即可选择其模型进行对话。
![连接远程API](./_assets/quick-start-03.png)
