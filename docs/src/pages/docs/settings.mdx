# 设置

要访问**设置**，请点击 Jan 左下角的 <Settings width={16} height={16} style={{display:"inline"}}/> 图标。

## 模型管理

在**设置** > **模型提供商**中管理已安装的 AI 模型：

### 导入模型

- **从 Hugging Face 导入：**
  - 在 Hub 搜索栏中输入模型的 Hugging Face ID（例如 `org/model_name_or_id`）。
  - **注意：** 某些模型需要 Hugging Face 访问令牌。请在**设置 > 模型提供商 > Hugging Face 访问令牌**中输入您的令牌。
- **从本地文件导入：**
  - 点击**导入模型**并选择您的 GGUF 文件。

### 移除模型

- 点击**启动**按钮旁的垃圾桶图标，然后点击**删除**。

### 启动模型

1. 打开一个新聊天并选择您想要启动的模型。
2. 在**设置 > 模型提供商**中点击**启动**按钮

### Hugging Face 访问令牌

要从 Hugging Face 下载需要身份验证的模型，例如 meta 的 llama 模型：

1. 从 [Hugging Face Tokens](https://huggingface.co/docs/hub/en/security-tokens) 获取您的令牌
2. 在 **设置 > 模型提供商 > Hugging Face** 中输入令牌

## 模型设置（齿轮图标）

![模型设置](./_assets/trouble-shooting-04.png)

点击模型旁的齿轮图标可配置高级设置：

- **上下文长度**：提示词的最大上下文长度
- **GPU 层数**：卸载到 GPU 的模型层数。若您使用 NVIDIA GPU 且发现模型无法完全加载，可降低此值分批加载模型后重试
- **温度值**：控制随机性（值越高结果越随机）
- **Top K**：限定模型仅从 K 个最可能的候选词中选择（K 值越小回答越集中）
- **Top P**：限定模型从累计概率达 P 的词集中选择（P 值越小回答越集中）
- **最小概率**：设置词语被选择的最低概率阈值（值越高会过滤更多低概率词）
- **重复检测窗口**：设定模型检查最近多少个词来避免重复
- **重复惩罚**：控制模型避免重复短语的强度（值越高重复越少）
- **存在惩罚**：降低已出现词语的复用概率（增加多样性）

_详见 [模型参数](/docs/model-parameters) 获取完整说明_

## 隐私

在 **设置** (<Settings width={16} height={16} style={{display:"inline"}}/>) > **隐私** 中，可管理 Jan 的分析与日志功能：

### 数据分析

Jan 以隐私保护为核心设计，默认不收集任何数据，所有信息仅存储于您的设备本地。
您可以通过分享匿名使用数据来帮助改进 Jan：

1. 开启 **数据分析** 以分享匿名数据
2. 可随时更改此设置

<Callout type="info">
详细了解我们为选择加入用户收集的数据，请参阅[隐私政策](/docs/privacy)。
</Callout>

<br/>

![数据分析](./_assets/settings-07.png)

- 从 Jan 界面打开日志：在 **日志** 页面，点击 <FolderOpen width={16} height={16} style={{display:"inline"}}/> 图标可打开应用日志和核心日志：

1. 在 **Jan 数据文件夹** 处，点击 <Pencil width={16} height={16} style={{display:"inline"}}/> 图标编辑应用文件夹

操作完成后需要重启应用。

4. 点击 **Yes, Proceed**（是，继续）

### HTTPS 代理

HTTPS 代理会加密浏览器与互联网之间的数据传输，防止外部人员截获或读取。它还能帮助您在绕过地区网络限制的同时保护隐私安全。

<Callout type="info">
- 由于加密/解密过程及云服务提供商的网络状况，模型下载速度可能受影响
- HTTPS 代理不会影响远程模型的使用
</Callout>

1. **启用**代理开关
2. 按以下格式输入代理服务器信息：

```
http://<user>:<password>@<domain or IP>:<port>
```

其中：

- `<user>`: 代理用户名（如需认证）
- `<password>`: 代理密码（如需认证）
- `<domain or IP>`: 代理服务器域名或IP地址
- `<port>`: 代理服务器端口号

<br/>

![HTTPS 代理](./_assets/settings-13.png)

<br/>

**忽略 SSL 证书**

此设置允许 Jan 接受自签名或未经验证的 SSL 证书。适用于以下情况：

- 使用内部证书在企业代理环境下工作
- 在开发环境中进行测试
- 通过特殊网络安全配置建立连接

<Callout type="info">
仅当您信任当前网络环境时启用此选项。
</Callout>

### 恢复出厂设置

"恢复出厂设置"会将 Jan 重置到初始状态，清除所有用户数据（包括下载的模型和聊天记录）。此操作不可逆，仅应在遇到严重应用问题时作为最后手段使用。

<Callout type="warning">
此操作不可撤销，所有数据将被永久删除。
</Callout>

仅在以下情况使用恢复出厂设置：

- 应用程序损坏
- 遇到其他解决方案无法解决的持续性技术问题
- 需要全新干净的安装环境

操作步骤：

1. 在 **恢复出厂设置** 处点击 **重置** 按钮

<br/>

![Jan 快速提问](./_assets/settings-17.png)

<br/>

2. 在确认对话框中：

- 输入 **RESET** 进行确认
- 可选勾选 **保留当前应用数据位置** 以维持原数据文件夹
- 点击 **立即重置**

3. 确认后需要重启应用

<br/>

![Jan 快速提问](./_assets/settings-18.png)
