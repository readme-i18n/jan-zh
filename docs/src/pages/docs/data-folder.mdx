# Jan 数据文件夹

Jan 以 JSON 格式将您的数据存储在本地。您的数据仅属于您个人。

## 打开 Jan 数据文件夹

通过 Jan 界面：

1. 设置 (<Settings width={16} height={16} style={{display:"inline"}}/>) > 高级设置
2. 点击 <FolderOpen width={16} height={16} style={{display:"inline"}}/>

<br/>

![打开 Jan 数据文件夹](./_assets/settings-11.png)

<br/>

通过终端：

```bash
# Windows
cd %APPDATA%/Jan/data

# Mac
cd ~/Library/Application\ Support/Jan/data

# Linux
cd $XDG_CONFIG_HOME/Jan/data  # Custom install
cd ~/.config/Jan/data         # Default install
```

### `assistants/`

存放 AI 个性配置。默认配置位于 (`/assistants/jan/`)：

```json
{
  "avatar": "👋",
  "id": "jan",
  "object": "assistant",
  "created_at": 1750945742.536,
  "name": "Jan",
  "description": "Jan is a helpful AI assistant that can use tools and help complete tasks for its users.",
  "model": "*",
  "instructions": "You have access to a set of tools to help you answer the user’s question. You can use only one tool per message, and you’ll receive the result of that tool in the user’s next response. To complete a task, use tools step by step—each step should be guided by the outcome of the previous one.\nTool Usage Rules:\n1. Always provide the correct values as arguments when using tools. Do not pass variable names—use actual values instead.\n2. You may perform multiple tool steps to complete a task.\n3. Avoid repeating a tool call with exactly the same parameters to prevent infinite loops.",
  "tools": [
    {
      "type": "retrieval",
      "enabled": false,
      "useTimeWeightedRetriever": false,
      "settings": {
        "top_k": 2,
        "chunk_size": 1024,
        "chunk_overlap": 64,
        "retrieval_template": "Use the following pieces of context to answer the question at the end.\n----------------\nCONTEXT: {CONTEXT}\n----------------\nQUESTION: {QUESTION}\n----------------\nHelpful Answer:"
      }
    }
  ],
  "file_ids": []
}
```

参数：

| 参数                   | 描述                                                  | 类型    | 默认值 |
|------------------------|-------------------------------------------------------|---------|--------|
| id                     | 助手标识符                                           | string  | jan    |
| avatar                 | 助手头像                                             | string  | 无     |
| object                 | OpenAI API 兼容标记                                  | string  | 无     |
| created_at             | 创建时间戳                                           | string  | 无     |
| name                   | 显示名称                                             | string  | Jan    |
| description            | 角色描述                                             | string  | 默认   |
| model                  | 允许使用的模型 (* 表示全部)                          | string  | *      |
| instructions           | 默认线程指令                                         | string  | 无     |
| file_ids               | OpenAI 兼容字段                                     | string  | 无     |
| tools                  | 可用工具 (当前仅支持检索功能)                        | array   | retrieval |
| type                   | 工具类型                                             | string  | retrieval |
| enabled                | 工具启用状态                                         | boolean | true   |
| useTimeWeightedRetriever| 时间加权检索开关                                   | boolean | false  |
| settings               | 工具配置                                             | object  | 无     |
| top_k                  | 最大检索结果数                                       | number  | 2      |
| chunk_size             | 文本分块大小                                         | number  | 1024   |
| chunk_overlap          | 分块重叠量                                           | number  | 64     |
| retrieval_template     | 响应格式模板                                         | string  | 无     |

### `extensions/`

插件中心。组织扩展位于 `@janhq/` 目录下，独立扩展直接存放在根目录。

### `logs/`

调试总部 (`/logs/app.txt`)：

- **[APP]**: 核心日志
- **[SERVER]**: API 运行记录
- **[SPECS]**: 硬件配置信息

### `models/`

模型仓库。每个模型都有独立的 `model.json` 配置文件。

<Callout type="info">
完整参数说明：[查看文档](/docs/model-parameters)
</Callout>

- `thread.json`:

| 参数        | 描述                                          |
|------------|-----------------------------------------------|
| assistants | 助手配置副本                                  |
| created    | 创建时间戳                                    |
| id         | 线程标识符                                    |
| metadata   | 附加线程数据                                  |
| model      | 当前模型设置                                  |
| object     | OpenAI 兼容标记                               |
| title      | 线程名称                                      |
| updated    | 更新时间戳                                    |
