# 开始聊天

<Steps>

### 第一步：安装 Jan

1. [下载 Jan](/download)
2. 安装应用（[Mac](/docs/desktop/mac)、[Windows](/docs/desktop/windows)、[Linux](/docs/desktop/linux)）
3. 启动 Jan

### 第二步：下载模型

Jan 需要模型才能进行对话。从 Hub 下载一个：

1. 进入 **Hub 标签页**
2. 浏览可用模型（必须为 GGUF 格式）
3. 选择与您硬件配置匹配的模型
4. 点击 **下载**

![下载模型](./_assets/model-management-01.png)

<Callout type="warning">
模型会占用内存和计算资源。请根据硬件配置选择。
</Callout>

**HuggingFace 模型：** 部分需要访问令牌。在 **设置 > 模型供应商 > Llama.cpp > Hugging Face 访问令牌** 中添加您的令牌。

![添加 HF 令牌](./_assets/hf_token.png)

### 第三步：启用 GPU 加速（可选）

适用于配备兼容显卡的 Windows/Linux 用户：

1. 进入 **（<Settings width={16} height={16} style={{display:"inline"}}/>）设置 > 硬件**
2. 将 **GPU** 开关切换为开启

![开启 GPU 加速](./_assets/gpu_accl.png)

<Callout type="info">
启用 GPU 加速前请安装所需驱动。参考 [Windows](/docs/desktop/windows#gpu-acceleration) 和 [Linux](/docs/desktop/linux#gpu-acceleration) 的设置指南。
</Callout>

### 第四步：开始对话

1. 点击 **新建对话**（<SquarePen width={16} height={16} style={{display:"inline"}}/>）图标
2. 在输入框下拉菜单中选择您的模型
3. 输入消息开始对话

![创建新会话](./_assets/threads-new-chat-updated.png)

</Steps>

## 会话管理

Jan 将对话组织成线程形式，便于追踪和回溯。

### 查看聊天记录

- **左侧边栏** 显示所有对话
- 点击任意聊天可展开完整对话
- **收藏夹**：置顶重要线程以便快速访问
- **最近记录**：访问近期使用过的线程

![收藏夹与最近记录](./_assets/threads-favorites-and-recents-updated.png)

### 编辑聊天标题

1. 将鼠标悬停在侧边栏的对话上
2. 点击 **三点菜单** (<Ellipsis width={16} height={16} style={{display:"inline"}}/>) 图标
3. 点击 <Pencil width={16} height={16} style={{display:"inline"}}/> **重命名**
4. 输入新标题并保存

![上下文菜单](./_assets/threads-context-menu-updated.png)

### 删除线程

<Callout type="warning">
线程删除操作不可逆，无法撤销。
</Callout>

**单个线程：**

1. 将鼠标悬停在侧边栏的线程上
2. 点击 **三点菜单** (<Ellipsis width={16} height={16} style={{display:"inline"}}/>) 图标
3. 点击 <Trash2 width={16} height={16} style={{display:"inline"}}/> **删除**

**全部线程：**

1. 将鼠标悬停在 `最近记录` 分类上
2. 点击 **三点菜单** (<Ellipsis width={16} height={16} style={{display:"inline"}}/>) 图标  
3. 选择 <Trash2 width={16} height={16} style={{display:"inline"}}/> **全部删除**

## 高级功能

### 自定义助手指令

定制模型响应方式：

1. 在输入框中使用助手下拉菜单
2. 或前往**助手选项卡**创建自定义指令
3. 指令适用于所有模型

![助手指令](./_assets/assistant-dropdown.png)

![添加助手指令](./_assets/assistant-edit-dialog.png)

### 模型参数

微调模型行为：

- 点击模型旁的**齿轮图标**
- 在**助手设置**中调整参数
- 通过**模型选择器**切换模型

![与模型对话](./_assets/model-parameters.png)

### 连接云端模型（可选）

连接 OpenAI、Anthropic、Groq、Mistral 等服务：

1. 打开任意会话线程
2. 从下拉菜单中选择云端模型
3. 点击服务商旁的**齿轮图标**
4. 添加您的 API 密钥（确保账户余额充足）

![连接远程API](./_assets/quick-start-03.png)

详细设置请参阅[远程API文档](/docs/remote-models/openai)。
