# Canva MCP

[Canva MCP](https://www.canva.com/newsroom/news/deep-research-integration-mcp-server/) 赋予AI模型直接在Canva平台内创建、搜索和管理设计作品的能力。作为首个原生集成MCP协议的设计平台，它允许您通过对话而非点击设计界面来生成演示文稿、徽标和营销素材。

该集成提供了全面的设计能力而无需离开聊天界面，但实际编辑仍需在Canva的设计界面中完成。

## 可用工具

<Callout type="info">
Canva的MCP工具可能会随着集成方案的演进发生变化。当前列表反映的是现有功能。
</Callout>

### 设计操作

- **generate-design**: 通过AI提示生成新设计
- **search-designs**: 搜索文档、演示文稿、视频、白板
- **get-design**: 获取Canva设计的详细信息  
- **get-design-pages**: 列出多页设计中的页面
- **get-design-content**: 从设计中提取内容
- **resize-design**: 调整设计尺寸以适应不同规格
- **get-design-resize-status**: 检查尺寸调整操作状态
- **get-design-generation-job**: 追踪AI生成进度

### 导入/导出

- **import-design-from-url**: 从URL导入文件作为新设计
- **get-design-import-from-url**: 检查导入状态  
- **export-design**: 以多种格式导出设计
- **get-export-formats**: 列出可用导出选项
- **get-design-export-status**: 追踪导出进度

### 组织管理

- **create-folder**: 在Canva中创建文件夹
- **move-item-to-folder**: 整理设计和资源
- **list-folder-items**: 浏览文件夹内容

### 协作功能

- **comment-on-design**: 在设计上添加评论
- **list-comments**: 查看设计评论
- **list-replies**: 查看评论对话
- **reply-to-comment**: 回复反馈

### 遗留工具

- **search**: ChatGPT连接器(建议改用search-designs)
- **fetch**: 为ChatGPT获取内容

## 前置条件

- 启用 MCP 的 Jan
- Canva 账户（免费或付费）
- 支持工具调用的模型
- 已安装 Node.js
- 可访问 Canva API 的网络连接

## 配置

### 启用MCP

1. 进入**设置** > **MCP服务器**
2. 将**允许所有MCP工具权限**切换为开启状态

![已启用切换按钮的MCP设置页面](../../_assets/mcp-on.png)

### 配置 Canva MCP 服务器

在MCP服务器区域点击`+`：

**配置步骤：**

- **服务器名称**: `Canva`
- **命令**: `npx`
- **参数**: `-y mcp-remote@latest https://mcp.canva.com/mcp`
- **环境变量**: 留空（通过 OAuth 处理认证）

![Jan 中的 Canva MCP 服务器配置](../../_assets/canva.png)

### 认证流程

首次使用 Canva 工具时：

1. **浏览器自动打开**
   - Canva 认证页面会出现在默认浏览器中
   - 使用您的 Canva 账户登录

![Canva 认证页面](../../_assets/canva2.png)

2. **团队选择与权限**
   - 选择您的团队（如果有多个）
   - 查看 AI 将获得的权限
   - 点击 **允许** 授予访问权限

![Canva 团队选择和权限](../../_assets/canva3.png)

权限包括：

- 读取您的个人资料和设计作品
- 创建新设计
- 管理文件夹和内容
- 访问团队品牌模板
- 在设计作品上评论

### 模型配置

使用支持工具调用的模型：

- **Anthropic Claude 3.5+ Sonnet**
- **OpenAI GPT-4o**
- **Google Gemini Pro**

## 工作流程技巧

### 高效设计生成

- **具体说明**："创建一个采用蓝银配色的极简科技公司徽标"
- **指定格式**："生成用于产品公告的 Instagram 故事模板"
- **包含背景**："为 AI 研究公司设计专业的 LinkedIn 横幅"
- **请求变体**：要求提供多个选项以供选择

### 组织最佳实践

- 生成多个设计前先创建文件夹
- 使用描述性名称以便后续搜索
- 立即将设计移至相应文件夹
- 导出重要设计作为备份

### 集成模式

- 生成设计 → 查看选项 → 选择偏好方案 → 在Canva中打开进行微调
- 搜索现有设计 → 提取内容 → 生成新版本
- 创建模板 → 为多平台调整尺寸 → 导出所有变体

## 限制与注意事项

**设计编辑**：虽然MCP可以创建和管理设计，实际编辑仍需通过Canva界面操作。

**项目访问**：集成可能无法立即访问所有历史项目，主要聚焦连接后创建或修改的设计。

**生成时间**：AI设计生成需要数秒时间，工具会提供任务ID用于追踪进度。

**团队权限**：访问权限取决于Canva团队设置和订阅等级。

## 故障排除

**认证问题**：

- 清除Canva的浏览器cookie
- 尝试退出并重新登录Canva
- 确保OAuth流程未被弹窗拦截
- 如适用请检查团队管理员权限

**设计生成失败**：

- 确认在所选团队中拥有创建权限
- 检查Canva订阅限制
- 先尝试更简单的设计提示词
- 确保网络连接稳定

**工具可用性**：

- 部分工具需要特定的 Canva 订阅计划
- 团队功能需要相应权限
- 确认 MCP 服务器显示为活跃状态
- 认证后需重启 Jan

**搜索问题排查：**

- 使用 search-designs（而非旧版搜索工具）
- 明确指定设计类型和名称
- 检查团队内容的文件夹权限
- 新设计需要时间完成索引
