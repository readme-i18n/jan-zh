# Browserbase MCP

[Browserbase MCP](https://docs.browserbase.com/integrations/mcp/introduction) 通过云基础设施为AI模型提供真实的浏览器控制能力。基于Stagehand构建，允许使用自然语言命令导航网站、提取数据并与网页交互。

该集成提供AI可控制的真实浏览器会话，实现超越简单网页搜索API的任务处理能力。

## 可用工具

<Callout type="info">
Browserbase的MCP工具会持续演进。当前列表反映现有功能，未来可能变更。
</Callout>

### 多会话工具

- `multi_browserbase_stagehand_session_create`: 创建并行浏览器会话
- `multi_browserbase_stagehand_session_list`: 追踪活跃会话
- `multi_browserbase_stagehand_session_close`: 清理会话
- `multi_browserbase_stagehand_navigate_session`: 在指定会话中导航

### 核心浏览器操作

- `browserbase_stagehand_navigate`: 导航至指定URL
- `browserbase_stagehand_act`: 执行操作（如"点击登录按钮"）
- `browserbase_stagehand_extract`: 提取文本内容
- `browserbase_stagehand_observe`: 查找页面元素
- `browserbase_screenshot`: 截取屏幕截图

### 会话管理

- `browserbase_session_create`: 创建或复用会话
- `browserbase_session_close`: 关闭活动会话

## 前置条件

- 已启用MCP的Jan
- Browserbase账户（包含60分钟免费使用时长）
- 支持强大工具调用的模型
- 已安装Node.js

<Callout type="warning">
当前仅最新版Anthropic模型能可靠处理多个工具。其他模型可能无法完整支持全部工具集。
</Callout>

## 配置

### 启用MCP

1. 进入**设置** > **MCP服务器**
2. 将**允许所有MCP工具权限**切换为开启状态

![已启用切换按钮的MCP设置页面](../../_assets/mcp-on.png)

### 获取Browserbase凭证

1. 在[browserbase.com](https://browserbase.com)注册账号
   - 需完成邮箱验证
   - 手机号认证
   - 严格的安全流程

2. 进入控制面板并复制：
   - **API密钥**
   - **项目ID**

![显示API密钥和项目ID的Browserbase控制面板](../../_assets/browserbase.png)

### 配置MCP服务器

在MCP服务器区域点击`+`：

**NPM包配置：**

- **服务器名称**: `browserbase`
- **命令**: `npx`
- **参数**: `@browserbasehq/mcp-server-browserbase`
- **环境变量**:
  - 键: `BROWSERBASE_API_KEY`, 值: `your-api-key`
  - 键: `BROWSERBASE_PROJECT_ID`, 值: `your-project-id`

![使用Browserbase设置的Jan MCP服务器配置](../../_assets/browserbase3.png)

### 验证设置

在聊天工具气泡中确认Browserbase工具可用:

![显示可用Browserbase工具的聊天界面](../../_assets/browserbase2.png)

## 常见问题

### 工具调用失败

有时工具调用会因解析问题失败:

![显示解析问题的工具调用错误](../../_assets/browserbase7.png)

**解决方案:**

- 尝试重新组织您的提示词
- 禁用不必要的工具
- 使用更简单直接的请求方式
- 如果使用其他模型，请切换至 Claude 3.5+ Sonnet

### 模型限制

大多数模型难以处理多工具协同。如遇问题：

- 从单一功能请求开始
- 逐步增加复杂度
- 评估实际需要的工具
- 初期需进行适当调试

## 使用限制

**免费层级：**

- 包含60分钟浏览器使用时间
- 5分钟无操作后会话自动终止
- 可在Browserbase仪表板调整超时设置
- 使用情况可见于仪表板分析

**会话管理：**

- 每个浏览器会话均计入使用时间
- 完成后关闭会话以节省分钟数
- 多会话操作会更快消耗时间

## 优化建议

**提示词工程：**

- 明确指定需要提取的内容
- 尽可能注明具体网站名称
- 将复杂任务分解为步骤
- 清晰定义输出格式

**工具选择：**

- 仅在需要时使用多会话模式
- 及时关闭会话
- 优先选择观察而非操作
- 谨慎使用截图以节省时间

**错误恢复：**

- 准备备用提示词
- 从简单开始，逐步增加复杂度
- 注意超时警告
- 在仪表盘中监控使用情况

## 故障排除

**连接问题：**

- 验证API密钥和项目ID
- 检查Browserbase服务状态
- 确保NPX可以下载包
- 配置后重启Jan

**浏览器故障：**

- 部分网站会阻止自动化操作
- 尝试不同的导航路径
- 检查网站是否需要登录
- 确认目标网站可访问

**性能问题：**

- 减少并发会话数
- 简化提取请求
- 检查剩余时间配额
- 考虑升级套餐

**模型处理困难：**

- 过多工具会使大多数模型不堪重负
- Claude 3.5+ Sonnet最为可靠
- 必要时减少可用工具数量
- 使用聚焦明确的指令

<Callout type="info">
浏览器自动化很复杂。预期偶尔会出现故障，并准备好调整您的方法。
</Callout>

## Browserbase与浏览器使用对比

| 功能特性 | Browserbase | 浏览器直接使用 |
|---------|-------------|-------------|
| **基础设施** | 云端浏览器 | 本地浏览器 |
| **配置复杂度** | 仅需API密钥 | 需Python环境 |
| **性能表现** | 稳定一致 | 依赖系统配置 |
| **成本** | 按用量计费 | 免费(消耗本地资源) |
| **可靠性** | 高 | 存在波动 |
| **隐私性** | 基于云端 | 完全本地化 |

## 后续步骤

Browserbase MCP提供真实的浏览器自动化能力，而非简单的网页搜索。这使得复杂工作流成为可能，例如表单填写、多站点监控和数据提取，这些功能是传统API无法实现的。

云端基础设施处理了浏览器的复杂性，同时Jan保持对话隐私性。只需谨记：强大的浏览器能力偶尔会伴随解析错误。
