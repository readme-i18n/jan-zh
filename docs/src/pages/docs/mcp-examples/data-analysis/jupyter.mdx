# Jupyter MCP

[Jupyter MCP Server](https://jupyter-mcp-server.datalayer.tech/) 实现了与 Jupyter notebook 的实时交互，允许 AI 模型编辑、执行和记录代码以进行数据分析和可视化。AI 不仅能生成代码建议，还能实际运行 Python 代码并查看结果。

该集成赋予 Jan 执行分析、创建可视化并根据实际结果迭代的能力——将您的 AI 助手转变为得力的数据科学合作伙伴。

<Callout type="info">
**重大变更**：0.11.0+ 版本将 `room` 重命名为 `document`。详情请查看[发布说明](https://jupyter-mcp-server.datalayer.tech/releases)。
</Callout>

## 可用工具

Jupyter MCP Server 提供 [12 种综合工具](https://jupyter-mcp-server.datalayer.tech/tools/)：

### 核心操作

- `append_execute_code_cell`: 在笔记本末尾添加并运行代码单元格
- `insert_execute_code_cell`: 在指定位置插入并运行代码
- `execute_cell_simple_timeout`: 带超时控制的单元格执行
- `execute_cell_streaming`: 支持进度更新的长时运行单元格
- `execute_cell_with_progress`: 带超时和监控的执行

### 单元格管理

- `append_markdown_cell`: 添加文档单元格
- `insert_markdown_cell`: 在指定位置插入Markdown
- `delete_cell`: 从笔记本中移除单元格
- `overwrite_cell_source`: 更新现有单元格内容

### 信息与读取

- `get_notebook_info`: 获取笔记本元数据
- `read_cell`: 检查特定单元格内容
- `read_all_cells`: 获取完整笔记本状态

<Callout type="warning">
MCP每次仅连接**一个笔记本**，不支持多笔记本操作。请在配置中指定目标笔记本。
</Callout>

## 前置条件

- 启用MCP的Jan环境
- Python 3.8+及uv包管理器
- 已安装Docker
- 访问GPT-5的OpenAI API密钥
- 基础的Jupyter笔记本知识

## 配置

### 启用MCP

1. 进入**设置** > **MCP服务器**
2. 将**允许所有MCP工具权限**切换为开启状态

![已启用切换按钮的MCP设置页面](../../_assets/mcp-on.png)

### 安装uv包管理器

若未安装uv：

```bash
# macOS and Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 创建Python环境

为Jupyter设置隔离环境：

```bash
# Create environment with Python 3.13
uv venv .venv --python 3.13

# Activate environment
source .venv/bin/activate  # Linux/macOS
# or
.venv\Scripts\activate     # Windows

# Install Jupyter dependencies
uv pip install jupyterlab==4.4.1 jupyter-collaboration==4.0.2 ipykernel
uv pip uninstall pycrdt datalayer_pycrdt
uv pip install datalayer_pycrdt==0.12.17

# Add data science libraries
uv pip install pandas numpy matplotlib altair
```

### 启动JupyterLab服务

带认证启动JupyterLab：

```bash
jupyter lab --port 8888 --IdentityProvider.token heyheyyou --ip 0.0.0.0
```

![显示JupyterLab启动的终端界面](../../_assets/jupyter1.png)

服务将在浏览器中打开：

![浏览器中的 JupyterLab 界面](../../_assets/jupyter.png)

### 创建目标笔记本

新建一个名为 `for_jan.ipynb` 的笔记本：

![JupyterLab 中创建的笔记本](../../_assets/jupyter2.png)

### 在 Jan 中配置 MCP 服务器

在MCP服务器区域点击`+`：

**macOS/Windows 配置：**

- **服务器名称**：`jupyter`
- **命令**：`docker`
- **参数**：
  ```
  run -i --rm -e DOCUMENT_URL -e DOCUMENT_TOKEN -e DOCUMENT_ID -e RUNTIME_URL -e RUNTIME_TOKEN datalayer/jupyter-mcp-server:latest
  ```
- **环境变量**：
  - 键：`DOCUMENT_URL`，值：`http://host.docker.internal:8888`
  - 键：`DOCUMENT_TOKEN`，值：`heyheyyou`
  - 键：`DOCUMENT_ID`，值：`for_jan.ipynb`
  - 键：`RUNTIME_URL`，值：`http://host.docker.internal:8888`
  - 键：`RUNTIME_TOKEN`，值：`heyheyyou`

![Jan MCP 服务器配置界面](../../_assets/jupyter3.png)

## 性能注意事项

<Callout type="warning">
多工具并行会快速消耗上下文窗口，尤其对本地模型影响显著。GPT-5的智能路由统一系统能有效管理，但本地模型可能在处理速度和上下文限制方面面临挑战。
</Callout>

### 上下文管理

- 每次工具调用都会增加对话历史记录
- 12个可用工具意味着显著的系统提示开销  
- 本地模型可能需要精简工具集以保证合理性能
- 建议禁用未使用的工具以节省上下文空间

### 云端与本地权衡

- **云端模型(GPT-5)**: 能高效处理多工具任务并支持大上下文窗口
- **本地模型**: 可能需要优化、精简工具集或缩小上下文尺寸  
- **混合方案**: 复杂多工具流程用云端，简单任务用本地

## 安全考量

<Callout type="warning">
MCP提供强大能力但需严格遵守安全规范。
</Callout>

### 认证令牌

- **始终使用强令牌** - 避免简单密码
- **切勿将令牌提交**至版本控制系统  
- **生产环境定期轮换**令牌
- **不同环境使用**不同令牌

### 网络安全

- JupyterLab通过`--ip 0.0.0.0`开放网络访问
- 建议使用`--ip 127.0.0.1`仅限本地访问  
- 实施防火墙规则限制访问
- 生产环境务必启用HTTPS

### 代码执行风险

- AI具备完整的Python执行能力
- 执行前请检查生成的代码
- 敏感操作请使用隔离环境
- 监控资源使用并设置限制

### 数据隐私

- 笔记本内容会被AI模型处理
- 使用GPT-5等云端模型时数据会离开本地系统
- 敏感数据请保存在安全环境中
- 需考虑模型提供商的数据政策

## 最佳实践

### 环境管理

- 使用虚拟环境实现隔离
- 记录必要的依赖项
- 对笔记本进行版本控制
- 定期清理环境

### 性能优化

- 从简单操作开始
- 执行过程中监控内存使用
- 关闭未使用的笔记本
- 需要时重启内核

### 高效提示技巧

- 明确指定期望输出
- 将复杂任务分解为步骤
- 要求附带代码解释
- 关键操作需包含错误处理

## 故障排除

**连接问题:**

- 确认JupyterLab正在运行
- 检查令牌与配置是否匹配
- 确保Docker可访问主机
- 使用curl测试连接性

**执行失败:**

- 检查Python包可用性
- 确认内核正在运行
- 检查生成代码中的语法错误
- 卡顿时重启内核

**工具调用错误:**

- 确保模型支持工具调用
- 验证所有12个工具是否出现在聊天中
- 检查MCP服务器是否活跃
- 查看Docker日志中的错误

**API速率限制:**

- 监控 OpenAI 使用情况仪表盘
- 针对瞬时错误实施重试机制
- 考虑回退到本地模型
- 尽可能缓存结果

## 结语

Jupyter MCP 集成与 GPT-5 的先进能力相结合，创造出了异常强大的数据科学环境。借助 GPT-5 内置的推理能力和专家级智能，过去需要大量手动编码的复杂分析现在可以通过自然对话完成。

无论是探索数据、构建模型还是创建可视化，该集成都能在 Jan 注重隐私的界面中，同时提供 Jupyter 的计算能力和 GPT-5 的智能。

谨记：强大的计算能力伴随着安全使用的责任。使用基于云的模型时，务必验证生成的代码、采用强身份验证机制，并时刻注意数据隐私。
