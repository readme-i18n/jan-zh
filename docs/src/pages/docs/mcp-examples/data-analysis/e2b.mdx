# E2B 代码沙盒 MCP

E2B MCP 提供隔离的 Python 执行环境。您的 AI 可以直接运行实际代码，而不仅限于描述代码可能的行为。

当您将安全的远程执行与 Jan 灵活的模型选择相结合时，真正的价值就会显现。您可以使用本地模型进行对话和推理，同时将实际计算任务卸载到 E2B 的沙盒中。这意味着您既能获得本地模型的隐私性和控制权，又能享受云基础设施的计算能力，而无需在本地管理复杂的 Python 环境或依赖项。

## 配置

### 环境要求

- 启用 MCP 的 Jan
- 从 [e2b.dev](https://e2b.dev/) 获取 E2B API 密钥
- 已安装 Node.js
- 支持工具调用的模型

### 配置

1. **启用 MCP**：进入 **设置** > **MCP 服务器**，将 **允许所有 MCP 工具权限** 切换为开启状态

![启用 MCP](../../_assets/mcp-on.png)

<Callout type="info">
请注意：在 Jan 的常规设置中开启实验性功能后，MCP 才会被激活。
</Callout>

2. **获取 API 密钥**：在 [e2b.dev](https://e2b.dev/) 注册并生成 API 密钥

![E2B API 密钥](../../_assets/e2b-key.png)

为您的密钥添加有意义的名称。

![E2B MCP 服务器](../../_assets/e2b-key1.png)

3. **添加 MCP 服务器**: 在 MCP 服务器区域点击 `+` 按钮

配置参数:

- **服务器名称**: `e2b-server`
- **命令**: `npx`
- **参数**: `@e2b/mcp-server`
- **环境变量**: 
  - 键: `E2B_API_KEY`
  - 值: `your-api-key`

![E2B MCP 服务器](../../_assets/e2b-key2.png)

4. **验证**: 确认服务器状态显示为活跃

![E2B MCP 服务器](../../_assets/e2b-key3.png)

## 图表生成

E2B 自动检测并从 matplotlib 代码中提取图表。图表以 base64 编码图像和可下载文件形式返回。

### 静态图表

```python
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 10, 100)
y = np.sin(x)

plt.figure(figsize=(10, 6))
plt.plot(x, y)
plt.title('Sine Wave')
plt.xlabel('x')
plt.ylabel('sin(x)')
plt.show()
```

E2B 捕获绘图并使其可供下载。

### 交互式图表

系统提取图表数据用于前端可视化：

```python
plt.bar(['A', 'B', 'C'], [10, 20, 15])
plt.title('Sample Bar Chart')
plt.show()
```

返回结构化数据：

```json
{
  "type": "bar",
  "title": "Sample Bar Chart", 
  "elements": [
    {"label": "A", "value": 10},
    {"label": "B", "value": 20},
    {"label": "C", "value": 15}
  ]
}
```

支持的图表类型：折线图、柱状图、散点图、饼图、箱线图。

## 故障排除

**连接问题：**

- 验证 API 密钥是否正确
- 检查 Node.js 安装情况
- 若服务器无法启动则重启 Jan

**执行问题：**

- 免费沙盒环境配备2核CPU和1GB内存 - 请从小型数据集开始
- 大型计算可能超时或内存不足
- 测试基础示例后逐步增加复杂度
- 某些软件包可能需要显式安装

**软件包安装：**

- 大多数数据科学包可成功安装
- 系统依赖可能导致部分包安装失败
- 安装失败时可尝试替代包

<Callout type="warning">
  E2B存在计算和内存限制。必要时请将大型操作拆分为小块处理。
</Callout>

## 使用场景

E2B适用于：

- **学术研究**：统计分析、数据可视化、假设检验

该沙盒环境提供隔离执行能力，无需本地环境设置或依赖管理。
