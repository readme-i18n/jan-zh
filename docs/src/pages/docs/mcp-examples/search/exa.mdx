# Exa Search MCP

[Exa MCP](https://docs.exa.ai/examples/exa-mcp) 为 AI 模型提供实时网络搜索能力。模型不再依赖训练数据，
而是通过 Exa 的搜索 API 访问当前网络内容。

## 可用工具

Exa MCP 包含八种搜索功能：

- `web_search_exa`: 支持内容提取的通用网络搜索
- `research_paper_search`: 学术论文与研究内容
- `company_research`: 公司分析与商业情报
- `crawling`: 从特定 URL 提取内容
- `competitor_finder`: 查找商业竞争对手
- `linkedin_search`: 搜索 LinkedIn 个人资料与企业
- `wikipedia_search_exa`: 维基百科内容检索
- `github_search`: 代码库与代码搜索

## 前置条件

- 已启用 MCP 的 Jan
- 从 [dashboard.exa.ai](https://dashboard.exa.ai/api-keys) 获取的 Exa API 密钥
- 支持工具调用的模型
- 已安装 Node.js

<Callout type="info">
不同模型对工具调用的支持程度各异。Jan Nano 32k 和 128k、Claude、Gemini、GPT-4o 及以上版本模型运行稳定。对于本地和远程模型，
请确认模型参数中已启用工具调用功能。
</Callout>

## 配置

### 启用MCP

1. 进入**设置** > **MCP服务器**
2. 将**允许所有MCP工具权限**切换为开启状态

![已启用切换按钮的MCP设置页面](../../_assets/mcp-on.png)

### 获取 API 密钥

1. 访问 [dashboard.exa.ai/api-keys](https://dashboard.exa.ai/api-keys)
2. 创建账户或登录
3. 生成 API 密钥
4. 保存密钥

![Exa API 密钥](../../_assets/exa.png)

### 配置MCP服务器

在MCP服务器区域点击`+`：

**配置步骤：**

- **服务器名称**: `exa`
- **命令**: `npx`
- **参数**: `-y exa-mcp-server`
- **环境变量**: 
  - 键: `EXA_API_KEY`
  - 值: `your-api-key`

![Exa Jan MCP 服务器](../../_assets/exa1.png)

### 验证设置

在 MCP 服务器列表中检查服务器状态。

![Exa Jan MCP 服务器](../../_assets/exa2.png)

## 故障排除

**连接问题：**

- 验证API密钥准确性
- 检查Node.js安装情况
- 重启Jan
- 确保Exa账户有足够额度

**工具调用问题：**

- 确认模型已启用工具调用功能
- 尝试Jan Nano 32k、Claude、Gemini及GPT-4o以上模型
- 检查MCP服务器状态

**搜索质量：**

- 使用具体、描述性强的查询语句
- 优先使用自然语言而非关键词

**API错误：**

- 在[dashboard.exa.ai](https://dashboard.exa.ai)验证API密钥
- 检查当前套餐的速率限制
- 必要时重新生成API密钥

<Callout type="warning">
Exa设有API调用频率限制。请检查套餐限额以避免服务中断。
</Callout>
