# llmcord (Discord)

## 将 llmcord.py 与 Jan 集成

[llmcord.py](https://github.com/jakobdylanc/discord-llm-chatbot) 允许您和您的朋友直接在 Discord 服务器中与 LLM 进行对话。

按照以下步骤将 Jan 与 llmcord.py 集成：

<Steps>

### 步骤 1：克隆代码仓库

使用以下命令克隆 Discord 机器人的[代码仓库](https://github.com/jakobdylanc/discord-llm-chatbot)：
```bash
git clone https://github.com/jakobdylanc/discord-llm-chatbot.git
```

### 步骤 2：安装依赖库

克隆完成后，运行以下命令：

```bash
pip install -r requirements.txt
```

<Callout type="info">
  需要已安装有效的 Python 环境。
</Callout>

### 步骤 3：配置环境变量

1. 复制 `.env.example` 文件
2. 重命名为 `.env`
3. 配置以下环境变量：

| 设置项                 | 说明                                                                                                                                                                                  |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DISCORD_BOT_TOKEN`     | 在 [discord.com/developers/applications](https://discord.com/developers/applications) 创建新的 Discord 机器人，从 Bot 标签页获取令牌，并启用 MESSAGE CONTENT INTENT 权限 |
| `DISCORD_CLIENT_ID`     | 在创建的 Discord 机器人 OAuth2 标签页下获取 |
| `LLM`                   | 使用 Jan 时设置为 `local/openai/(MODEL_NAME)`，其中 `(MODEL_NAME)` 是已加载的模型名称 |
| `LLM_SYSTEM_PROMPT`  | 根据需要调整机器人的行为提示 |
| `LOCAL_SERVER_URL`      | 本地 API 服务器地址。使用 Jan 时设置为 `http://localhost:1337/v1` |

更多配置选项请参考 llmcord.py 的 [README](https://github.com/jakobdylanc/discord-llm-chatbot/tree/main?tab=readme-ov-file#instructions) 文件。

### 步骤 4：运行机器人

在命令行中执行以下命令启动机器人：

```bash
python llmcord.py
```

控制台将打印机器人的邀请链接，使用该链接将机器人添加到您的服务器。

</Steps>
