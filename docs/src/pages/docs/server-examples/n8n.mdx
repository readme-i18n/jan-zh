# n8n

## 将n8n与Jan集成

[n8n](https://n8n.io/) 是一款开源工作流自动化工具，可连接400多种集成和服务来自动化重复任务。通过其可视化界面，您可以便捷地创建复杂工作流。要将n8n与Jan集成，请按照以下步骤操作：

<Steps>
### 步骤 1: 通过 Jan server 运行您选择的模型

1. 打开 Jan 应用程序
2. 进入 **Hub** 并下载您选择的模型
3. 启动 Jan 服务器

### 步骤 2: 启动 n8n 服务
使用 npx 立即启动 n8n：

```
npx n8n
```

或通过 Docker 部署：

```
docker run -it --rm --name n8n -p 5678:5678 docker.n8n.io/n8nio/n8n
```

### 步骤 3: 使用 HTTP 请求将 Jan 与 n8n 服务集成

在 n8n 中选择 HTTP 请求节点并导入以下 cURL 命令来集成 Jan：

```bash
curl -X 'POST' \
  'http://127.0.0.1:1337/v1/chat/completions' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "messages": [
    {
      "content": "You are a helpful assistant.",
      "role": "system"
    },
    {
      "content": "Hello!",
      "role": "user"
    }
  ],
  "model": "tinyllama-1.1b",
  "stream": true,
  "max_tokens": 2048,
  "stop": [
    "hello"
  ],
  "frequency_penalty": 0,
  "presence_penalty": 0,
  "temperature": 0.7,
  "top_p": 0.95
}'
```

</Steps>
