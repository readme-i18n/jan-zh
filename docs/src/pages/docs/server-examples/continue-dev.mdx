# Continue.dev

## 与 Continue VS Code 集成

[Continue](https://continue.dev/docs/intro) 是一款兼容 Visual Studio Code 和 JetBrains 的开源自驾系统，提供了使用任何 LLM（本地语言模型）进行编码的最简方法。

要将 Jan 与本地 AI 语言模型集成，请按照以下步骤操作：

<Steps>
### 步骤1：在 Visual Studio Code 上安装 Continue

按照此[指南](https://continue.dev/docs/quickstart)在 Visual Studio Code 上安装 Continue 扩展。

### 步骤2：启用 Jan API 服务器

要将 Continue 与 Jan 本地服务器配合使用，您需要使用所选模型激活 Jan API 服务器。

1. 点击 `⚙️ 设置` 按钮。
2. 找到 `Local API Server`。
3. 配置服务器，包括 **IP 端口**、**跨域资源共享 (CORS)** 和 **详细服务器日志**。
4. 添加您自定义的 API 密钥。
5. 点击 **Start Server** 按钮。

### 步骤3：配置 Continue 使用 Jan 本地服务器

1. 进入 `~/.continue` 目录。

<Tabs items={['Mac', 'Windows', 'Linux']}>
    <Tabs.Tab value="mac" label="Mac" default>
    ```bash
    cd ~/.continue
    ```
    </Tabs.Tab>
    <Tabs.Tab value="windows" label="Windows">
    ```bash
    C:/Users/<your_user_name>/.continue
    ```
    </Tabs.Tab>
    <Tabs.Tab value="linux" label="Linux">
    ```bash
    cd ~/.continue
    ```
    </Tabs.Tab>
</Tabs>

```yaml title="~/.continue/config.yaml"
name: Local Assistant
version: 1.0.0
schema: v1
models:
  - name: Jan
    provider: openai
    model: #MODEL_NAME (e.g. qwen3:0.6b)
    apiKey: #YOUR_USER_DEFINED_API_KEY_HERE (e.g. hello)
    apiBase: http://localhost:1337/v1
context: 
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase
```

2. 确保文件包含以下配置：
  - 确保选择 `openai` 作为 `provider`。
  - 确保 `model` 与 Jan API 服务器中启用的模型匹配。
  - 将 `apiBase` 设置为 `http://localhost:1337/v1`。

### 步骤4：确保在 Jan 中激活使用的模型

1. 导航至 `Settings` > `Model Providers`。
2. 在 Llama.cpp 下找到您想要使用的模型。
3. 点击 **Start Model** 按钮以激活模型。

</Steps>

## 如何在 Visual Studio Code 中使用 Jan 与 Continue 集成

### 1. 使用 Jan 探索代码

1. 选中一段代码
2. 按下 `Command + Shift + M` 打开左侧面板
3. 点击面板底部的 "Jan" 并提交查询，例如 `解释这段代码`

### 2. 借助大语言模型增强代码

1. 选择代码片段
2. 按下 `Command + Shift + L`
3. 输入具体需求，例如 `为这段代码添加注释`
