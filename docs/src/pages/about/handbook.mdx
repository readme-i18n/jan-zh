# 工作方式

Jan 遵循开源原则运作，赋予每个人调整、个性化及参与开发的权利。我们致力于打造一个以社区驱动的生态系统，强调透明度、可定制性和用户隐私。更多原则详见[关于页面](https://jan.ai/about)。

## 开源

我们践行开放开发模式，在 GitHub 上展示进展与规划功能，诚邀您参与贡献：

- [Jan Framework](https://github.com/menloresearch/jan) (AGPLv3)
- [Jan 桌面客户端 & 本地服务器](https://jan.ai) (基于 Jan Framework，AGPLv3)
- [Nitro: 本地 AI 运行引擎](https://github.com/menloresearch/nitro) (AGPLv3)

## 公开构建

我们通过 GitHub 进行公开开发，欢迎任何人参与协作。

## 协作

我们的团队遍布全球，通过远程协作共同开发 Jan。我们主要通过 Discord 和 GitHub 进行协调，推崇异步沟通方式，并保持会议精简高效。在协作与头脑风暴环节，我们使用 [Excalidraw](https://excalidraw.com/) 和 [Miro](https://miro.com/) 等工具，通过视觉化叙事和 [HackMD](https://hackmd.io/) 上的详细文档确保团队目标一致、愿景共享。

欢迎探索采用 AGPLv3 许可证的 [Jan Framework](https://github.com/menloresearch/jan) 框架（保障最大开放性与用户自由），以及我们的桌面客户端和本地服务器 [jan.ai](https://jan.ai)。
