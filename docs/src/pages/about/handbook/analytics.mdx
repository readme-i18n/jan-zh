# 分析体系

秉承 Jan 保护隐私的理念，我们的分析哲学是获取"刚好够用"的数据。

## 追踪内容

1. 默认情况下，GitHub 会追踪所有公开仓库的下载量和设备元数据。这有助于我们排查问题并确保跨平台支持。
2. 此外，我们计划在`设置`中提供关闭所有追踪的功能选项。
