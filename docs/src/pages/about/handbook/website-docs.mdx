# 网站与文档

本网站使用现代静态网站生成器 [Docusaurus 3.0](https://docusaurus.io/) 构建

## 信息架构

我们努力**保持路由一致性**以维护SEO效果

- **`/guides/`**: Jan应用程序使用指南，面向直接使用Jan的终端用户

- **`/developer/`**: 关于如何扩展Jan的开发者文档，这些页面介绍用户能基于我们的软件构建什么

- **`/api-reference/`**: Jan API服务器的参考文档，采用Swagger/OpenAPI格式编写

- **`/changelog/`**: Jan应用程序各版本的变更记录

- **`/blog/`**: Jan应用程序的官方博客

## 如何贡献

请参阅[贡献指南](https://github.com/menloresearch/jan/blob/dev/CONTRIBUTING.md)获取关于如何参与Jan项目开发的完整信息

## 环境要求与安装

- [Node.js](https://nodejs.org/en/) (20.0.0或更高版本)
- [yarn](https://yarnpkg.com/) (1.22.0或更高版本)

### 安装

```bash
cd jan/docs
```

```bash
yarn install && yarn start
```

该命令会启动本地开发服务器并自动打开浏览器窗口。大多数更改都能实时反映，无需重启服务器。

### 构建

```bash
yarn build
```

此命令将静态内容生成到 `build` 目录中，可通过任何静态内容托管服务进行部署。

### 部署指南

使用 SSH：

```bash
USE_SSH=true yarn deploy
```

不使用 SSH：

```bash
GIT_USER=<Your GitHub username> yarn deploy
```

若使用 GitHub Pages 进行托管，该命令可便捷地构建网站并推送至 `gh-pages` 分支。

### 预览链接、预发布与文档发布

- 创建拉取请求时，系统会自动在请求中评论预览链接

- 当拉取请求合并至 `main` 分支后，文档将发布至 [https://dev.jan.ai/](https://dev.jan.ai/)

- 我们的开源维护者会将 `main` 分支的更新内容同步至 `release` 分支，随后发布至 [https://jan.ai/](https://jan.ai/)
