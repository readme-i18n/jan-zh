# 愿景

> "我不畏惧计算机，我畏惧的是没有计算机" —— 艾萨克·阿西莫夫

![太阳能朋克文明](./_assets/solarpunk.jpeg)

- 人类、自然与机器的和谐共生
- 数千年间，人类不断接纳新工具：火、电力、计算机，以及AI
- AI并无不同，它是能推动人类进步的工具
- 我们拒绝
- 超越《沙丘》与《终结者》的末日叙事，你会发现进步的核心

我们希望能延续工匠精神，打造推动人类进步的工具。

## 与思考机器协作

我们的愿景是开发能与人类协同工作的思考机器。

我们展望这样的未来：AI能像火与电力一样，安全地成为日常生活的工具。这些机器人增强人类潜能，而非取代我们的关键决策权。你拥有属于自己的AI。

## 太阳能朋克，而非沙丘

我们的愿景植根于对AI在人类未来中角色的乐观展望。

如同[太阳能朋克运动](https://en.wikipedia.org/wiki/Solarpunk)所倡导的，我们设想一个科技与自然和谐共存的世界，共同维系可持续繁荣的生态系统。

我们聚焦AI对世界的积极影响。从环境保护到能源民主化，AI有潜力解决地球面临的一些最紧迫挑战。
