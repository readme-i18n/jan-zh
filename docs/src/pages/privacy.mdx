# 隐私政策

Menlo Research 致力于保护您的隐私，确保您的个人信息得到安全且负责任的处理。本政策概述了您在使用我们任何产品时，我们如何收集、存储和使用您的个人信息。

## 数据收集

Jan、Cortex 及所有 Menlo Research 产品均不会收集个人身份信息。您可以在此了解[我们的理念](/about#philosophy)并审计我们的开源代码库。

### 当您主动提供数据时

我们会收集您自愿提供的个人信息，例如当您订阅我们的新闻通讯、加入 Discord 社区或通过电子邮件联系我们时。

### Jan

Jan 默认以隐私保护模式运行，100% 在您的本地计算机上离线使用。您的数据（如对话历史、使用日志）仅存储在本地，永远不会离开您的设备。

<Callout type="info">
如果您使用远程 AI API（如 OpenAI API、Groq API），您的数据将自然传输至其服务器，并受相应 API 提供商的隐私政策约束。
</Callout>

### Cortex

Cortex 是一个在您本地计算机上运行大语言模型（LLM）的库，不会收集任何个人信息。

## 数据共享

除非法律要求或为您提供所请求服务所必需，我们不会与第三方共享您的个人信息。

## 数据安全

我们高度重视您的个人信息安全，已实施适当的技术和组织措施，以保护您的个人信息免遭未经授权的访问、披露或滥用。

## 您的选择权

您有权随时访问、更新和删除您的个人信息。如果您订阅了我们的新闻通讯，也可以通过邮件中的退订链接选择停止接收我们的营销信息。

## 联系我们

如对本隐私政策有任何疑问或顾虑，请通过 hello@menlo.ai 联系我们。
