# 在本地设备上运行 DeepSeek R1（新手友好指南）

![Jan AI 界面中本地运行的 DeepSeek R1，展示聊天界面和模型设置](./_assets/deepseek-r1-locally-jan.jpg)

DeepSeek R1 是当前市场上最优秀的开源模型之一，您完全可以在自己的电脑上运行它！

<Callout type="info">
初次尝试本地运行 AI 模型？建议先阅读[本地运行 AI 模型指南](/post/run-ai-models-locally)。该指南涵盖了基础概念，能帮助您更好地理解本 DeepSeek R1 教程。
</Callout>

DeepSeek R1 需要数据中心级硬件才能发挥全部性能，我们将使用适用于普通电脑的优化版本。

为何要使用优化版本？

- 在标准硬件上实现高效性能
- 更快的下载和初始化速度
- 优化的存储需求
- 保留原始模型的大部分能力

## 快速步骤概览

1. 下载 [Jan](https://jan.ai/)
2. 选择模型版本
3. 配置参数
4. 设置提示词模板并开始使用 DeepSeek R1

下面我们将逐步详细介绍每个步骤。

## 第一步：下载 Jan

[Jan](https://jan.ai/) 是一个开源应用程序，可让你在本地运行 AI 模型。它支持 Windows、Mac 和 Linux 系统。对于初学者来说，Jan 是最佳入门选择。

![Jan AI 界面，显示下载按钮](./_assets/download-jan.jpg)

1. 访问 [jan.ai](https://jan.ai)
2. 下载适合你操作系统的版本
3. 安装应用程序

## 第二步：选择 DeepSeek R1 版本

要在计算机上运行 DeepSeek R1 等 AI 模型，你需要 VRAM（显存）。可以将 VRAM 视为计算机用于处理复杂任务（如游戏或运行 AI 模型）的专用内存。它与常规 RAM 不同——VRAM 是显卡（GPU）的一部分。

<Callout type="info">
本地运行 AI 模型就像运行一个非常复杂的视频游戏——它需要专用内存来处理 AI 的所有"思考"。VRAM 越大，就能运行更强大、更复杂的 AI 模型。
</Callout>

首先检查您的电脑有多少显存。别担心显存不足——DeepSeek R1 有针对各类电脑的版本！

查看显存很简单：

- Windows 系统：按下 `Windows + R`，输入 `dxdiag`，回车后在"显示"选项卡查看
- Mac 系统：点击苹果菜单，选择"关于本机"，点击"更多信息"，在"图形/显示器"下查看
- Linux 系统：打开终端，输入 `nvidia-smi`（NVIDIA显卡）或 `lspci -v | grep -i vga`（其他显卡）

<Callout>
**没有独立显卡？** 没关系！您仍可运行 DeepSeek R1 的小型版本。这些版本专门针对基础图形性能的电脑进行了优化。
</Callout>

了解显存后，以下是适合您的 DeepSeek R1 版本推荐：

- 6GB 显存：选择 1.5B 版本——快速高效
- 8GB 显存：可运行 7B 或 8B 版本，功能更强大
- 16GB 及以上显存：可运行具备增强功能的大型模型

DeepSeek R1 各版本及基本需求：

| 版本 | 模型链接 | 所需显存 |

| Qwen 7B | [DeepSeek-R1-Distill-Qwen-7B-GGUF](https://huggingface.co/bartowski/DeepSeek-R1-Distill-Qwen-7B-GGUF) | 8GB+ |
| Llama 8B | [DeepSeek-R1-Distill-Llama-8B-GGUF](https://huggingface.co/unsloth/DeepSeek-R1-Distill-Llama-8B-GGUF) | 8GB+ |
| Qwen 14B | [DeepSeek-R1-Distill-Qwen-14B-GGUF](https://huggingface.co/bartowski/DeepSeek-R1-Distill-Qwen-14B-GGUF) | 16GB+ |
| Qwen 32B | [DeepSeek-R1-Distill-Qwen-32B-GGUF](https://huggingface.co/bartowski/DeepSeek-R1-Distill-Qwen-32B-GGUF) | 16GB+ |
| Llama 70B | [DeepSeek-R1-Distill-Llama-70B-GGUF](https://huggingface.co/unsloth/DeepSeek-R1-Distill-Llama-70B-GGUF) | 48GB+ |

下载所选模型步骤：

启动 Jan 并通过侧边栏导航至 Jan Hub

![Jan AI界面，显示模型库](./_assets/jan-library-deepseek-r1.jpg)

3. 在此字段输入模型链接：

![Jan AI界面，显示模型链接输入字段](./_assets/jan-hub-deepseek-r1.jpg)

## 步骤3：配置模型设置

配置模型时，您将看到量化选项：

<Callout type="tip">
量化技术平衡性能与资源消耗：
- **Q4:** 推荐大多数用户使用 - 效率与质量的最佳平衡点
- **Q8:** 更高精度但需要更多计算资源
</Callout>

## 步骤4：配置提示词模板

最终配置步骤：

1. 通过侧边栏进入模型设置
2. 定位到提示词模板配置项
3. 使用以下特定格式：

<Callout type="warning">
```
<|User|>{prompt}<|Assistant|>
```
</Callout>

该模板用于确保您与模型间的正确通信格式
