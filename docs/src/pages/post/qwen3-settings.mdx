# 本地运行 Qwen3-30B-A3B 的最佳参数设置

若需在本地运行 Qwen3-30B-A3B 模型，不必盲目猜测参数配置。本指南基于官方文档和实践验证，提供切实可行的设置方案。

<Callout>
**速览要点：**
- Qwen3-30B-A3B 具备两种模式：思考模式与非思考模式
- 每种模式需要不同的生成参数
- 贪心解码会破坏思考模式——务必避免使用
- 不要在聊天历史中记录 &lt;think&gt; 标记块
</Callout>

Qwen3 具有独特的功能开关：`enable_thinking`。启用时，模型会进入"思考"状态——分解问题、逐步推理，并将部分输出包裹在 `<think>...</think>` 标记块中。关闭时，模型将跳过这些步骤直接输出答案。

这直接影响您的参数配置方式。

---

### 思考模式 (`enable_thinking=True`)

该模式适用于需要逐步推导的场景：逻辑推理、数学运算、代码编写等。

**推荐生成参数：**

```vbnet
Temperature: 0.6  
TopP: 0.95  
TopK: 20  
Max tokens: 32,768  
Do not use greedy decoding
```

<Callout type="info">
**重要性说明：**
思维模式虽强大，但贪婪解码会破坏其输出效果。它会导致重复或卡顿。坚持使用采样方式，并预留足够的token空间让其完成思考过程。
</Callout>

### 非思维模式 (`enable_thinking=False`)

适用于快速通用回复场景。指令跟随、聊天对话、创意写作等——不生成`<think>`区块，无额外处理步骤。

**推荐参数设置：**

```makefile
Temperature: 0.7  
TopP: 0.8  
TopK: 20
```

<Callout type="info">
非思维模式更快速高效，默认token长度通常足够。若非处理长文本任务，无需调整此参数。
</Callout>

---

## 软切换与硬切换

可通过提示词动态切换思维模式：

```bash
/think      # turns thinking ON
/no_think   # turns it OFF
```

注意：仅当代码中设置`enable_thinking=True`时软切换才生效。若设为False，软切换指令将无效。

---

### 常见误区

- **不要将`think`区块存入聊天历史**。Qwen建议仅保留最终答案，否则后续回复会变得冗长且偏离主题。
- **贪婪解码是个陷阱**。虽然能保证一致性，但Qwen3的输出质量会下降——有时甚至会出现错误——必须使用采样方式。
- **并非总需YaRN扩展**。模型默认支持32k上下文，仅当常规超出该范围时才需启用YaRN。

## 在Jan中本地运行Qwen3

在本地运行 Qwen3-30B-A3B 最简单的方式是通过 Jan。

1. 下载并安装 [Jan](https://jan.ai)
2. 打开 Jan 并导航至 Jan Hub
3. 在模型列表中找到 `Qwen3` 和 `Qwen3-30B-A3B`
4. 点击"下载"获取模型

### Jan Hub 中的 Qwen3

您可以在 Jan Hub 中轻松找到 Qwen3 系列模型：

![Qwen3 in Jan Hub](./_assets/qwen3-in-jan-hub.jpeg)

下载完成后，Jan 会自动处理所有技术配置，您只需专注于使用模型而无需手动设置。本指南中提到的所有配置参数都会在通过 Jan 使用 Qwen3 时自动生效。

### 如何在 Jan 中自定义 Qwen3-30B-A3B 设置

您随时可以打开 Jan 的右侧面板，根据需要调整参数来自定义设置。

![Qwen3 settings in Jan app](./_assets/qwen3-settings-in-jan.jpeg)

## 核心建议

如果在本地运行 Qwen3-30B-A3B，请将其视为二合一模型。根据任务类型切换思维模式，相应调整生成参数，让其发挥最佳性能。
